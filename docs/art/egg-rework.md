# 알 디자인 개정

## 적용 범위

20개 스테이지, 각 5개 일반 알 변형의 C~Secret 외형과 20개 전용 드래곤 알에 공통 생성기를 적용한다. 월드, 자신/상대 운반, 보관, 획득, 부화, UI 아이콘은 같은 복셀 데이터를 사용한다. 기존 스테이지 정보가 없는 알도 기존 지역으로 테마를 선택한다. 이름·ID·확률·HP·부화 풀은 유지한다.

## 형태와 색

- 20³ 정수 복셀. 중심 껍질은 둥근 씨앗, 낮고 넓은 조개, 세로 캡슐, 각진 기계, 절단면 광물의 비율로 구분한다.
- 동일 스테이지/등급에서 실제로 나올 수 있는 펫의 주색을 참조한다. 배·아랫면·밝은 윗면을 넓은 색면으로 구분하며 작은 점무늬로 면을 채우지 않는다.
- 조개, 책, 등롱, 열쇠 등 기존 이름에 해당하는 변형의 큰 외곽 특징은 보존한다. 기존 공통 중심 몸체는 새 껍질로 바꾸고 바깥 구조를 합성한다.
- 높은 등급에는 열린 껍질과 내부 코어, 스테이지별 외곽 구조를 사용한다. 드래곤 알은 넓은 받침/날개형 껍질/외부 골격과 봉인을 가진다.
- 부화 결과는 기존과 같이 스테이지·등급 풀에서 결정된다. 특정 알 변형이 특정 펫을 보장하지 않으므로 알에 펫의 확정 초상화를 넣지는 않는다.

## 효과와 표시

꽃잎, 기계 궤도, 물방울, 불씨, 별 궤도를 실제 환경에 대응시킨다. 알 입자 수는 등급별 0/2/3/5/8/12/16이며 본체 바깥과 바닥에 둔다. 공통 거대 날개·왕관·무지개 광선 대신 스테이지 강조색을 쓴다. 공유 InstancedMesh 구조, 저사양 입자 축소, 모션 줄이기를 유지한다. 외부 효과 파일은 추가하지 않았다.

아이콘 출력은 192px이며 모델 규격은 20³다. 모델·아이콘 캐시 키에 등급을 포함한다. 보관/획득 크기 1.5와 월드 크기 3은 유지한다.

## 검수 상태

이번 요청에는 별도 자동 검증 지시가 없어 빌드·스크린샷·화면 비교·성능 검사를 실행하지 않았다. 디자인의 작은 화면 가독성, 좌우 대칭, 실제 광원하 색상, 형상 겹침은 미검수다. 개발 서버의 `/docs/art/egg-design-gallery.html`에서 스테이지별 컬러·회색·실루엣 비교를 볼 수 있다. 이 페이지는 실제 모델 데이터에서 아이콘을 생성하며 촬영한 검수 결과물이 아니다.

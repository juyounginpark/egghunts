## 1. 공식 스타일 선언

공식 스타일은 **굵은 복셀 덩어리, 단순한 점눈과 짧고 읽기 쉬운 얼굴, 기울어진 연결 파츠로 표현하는 곡선, 역할이 분명한 색면, 몸과 연결된 대표 오브제**를 중심으로 한다.

소장하고 싶은 인상은 세부 부품 수보다 기억에 남는 실루엣, 얼굴, 소재, 짧은 행동의 조합으로 만든다. 귀여움이 기본인 종도 있고 신비롭거나 위엄 있거나 기묘한 종도 있다. 모든 종을 같은 아기 동물 비율이나 같은 네 발 몸통으로 바꾸지 않는다.

포켓몬, 팰월드, 길건너친구들, Roblox 수집 게임은 제작 의도를 설명하는 보조 사례다. 새로운 외부 이미지를 찾았다는 이유로 공식 스타일을 교체하거나 서로 다른 얼굴·복셀 밀도·재질을 섞지 않는다. 현재 프로젝트의 공식 자료와 첨부 220종 문서가 직접적인 제작 기준이다.

스타일 지정은 원본 모델을 일괄 수정하라는 지시가 아니다. 원본 220종과 현재 저장 데이터는 보존한다. 신규 제작 및 명시적으로 지정된 확장 세트의 외형 수정에 적용한다.

## 3. 조형·눈·파츠의 공통 규칙

- 생물 또는 존재 1개와 소재·현상 1개의 조합을 먼저 정한다. 대표 특징 1개를 크게 만들고 보조 특징은 1~2개로 정리한다.
- 큰 머리, 짧은 다리, 넓은 볼은 종에 맞는 경우에 사용한다. 긴 몸, 직립형, 날개형, 낮고 넓은 몸도 같은 복셀 표현 안에서 허용한다.
- 작은 검정 또는 짙은 점눈을 기본으로 한다. 종별로 눈 간격·높이·볼 너비·주둥이 길이를 조절한다. 기존 공식 모델에 다른 눈 표현이 있으면 해당 종의 예외로 기록한다.
- 큰 홍채, 눈 테두리, 긴 코, 볼터치, 두꺼운 크림색 얼굴판을 일괄 적용하지 않는다. 어두운 몸에서는 주변 명도나 작은 하이라이트로 눈을 읽히게 한다.
- 얼굴 부품은 머리의 로컬 좌표계를 공유한다. 머리가 움직여도 눈·입이 떨어지거나 파묻히지 않게 한다.
- ‘둥글다’는 큰 복셀 외곽의 인상이다. 모든 몸을 매끈한 구체로 바꾸거나 복셀을 잘게 쪼개 곡면을 만들지 않는다.
- 50³ 또는 24³의 정육면체 규격을 모든 종에 강제하지 않는다. 같은 복셀 단위와 면 처리 수준을 유지하면서 종별 비율을 확보한다.
- 목·꼬리·귀·뿔·날개는 연결점, 로컬 위치, 회전, 크기를 가진다. 파츠를 기울이고 굵기를 점진적으로 바꿔 큰 흐름이 곡선처럼 읽히게 한다.
- 긴 꼬리는 원문 예시처럼 4~7개의 큰 구간부터 시험할 수 있다. 이는 시작값이며 모든 종의 고정 사양이 아니다. 작은 썸네일에서 충분히 읽히면 더 나누지 않는다.
- 귀 바깥쪽 10~20도, 날개 뒤쪽 15~30도 역시 원문의 시험값이다. 실제 참조 모델과 카메라에서 확인해 조절한다.
- 정면의 눈·다리·귀·날개 뿌리는 중심선에 맞춰 대칭으로 구성한다. 자세의 의도적 비대칭은 허용한다. 미러링 시 모든 회전축의 부호를 일괄 반전하지 않는다.
- 실·수염·다리·안테나는 가느다란 개념이어도 화면에서 읽히는 굵기를 확보한다. 부속물의 최소 두께는 실제 기준 모델과 같은 조건에서 비교한다.

## 4. 색·그라데이션·재질·효과

### 색의 역할

몸의 주색 1~2개, 보조 부위 색, 포인트색을 정한다. 색의 개수보다 각 색이 차지하는 면적과 명도 차이를 관리한다. 얼굴과 대표 오브제가 먼저 보이게 한다.

스테이지의 공통 요소는 소재·문양·부속물에 반복한다. 같은 스테이지의 모든 몸을 초록색, 파란색, 금색으로 통일하지 않는다. 종마다 주된 색과 실루엣은 구별되어야 한다.

채도는 전역 슬라이더로 일괄 올리지 않는다. 몸의 넓은 면은 형태를 읽을 수 있게 두고, 핵심 오브제와 필요한 포인트에 선명한 색을 집중한다. 신비로운 스테이지에서도 얼굴이 빛과 배경에 묻히지 않게 한다. 정확한 색상값은 확인된 레퍼런스에서 추출하거나 신규 팔레트로 명시한다.

### 그라데이션

기본은 소재의 방향을 따라가는 2~3단계 색 변화다. 복셀마다 무작위로 색을 흔드는 노이즈는 피한다. 조명에 의한 명암과 모델 자체의 색 패턴을 구분한다.

| 소재 | 원문 기준의 색 변화 |
| --- | --- |
| 딸기 | 아래 진홍 → 위 선명한 빨강 |
| 잎 | 뿌리 진초록 → 끝 연두 |
| 꿀 | 두꺼운 부분 호박색 → 얇은 가장자리 밝은 금색 |
| 날개 | 뿌리 진보라 → 끝 연보라 등 부위 방향에 따른 변화 |
| 불 | 밝은 노란 중심 → 주황·적색 외곽 |
| 얼음 | 두꺼운 부분 청록 → 얇은 끝 청백색 |

연속 그라데이션은 꿀·보석·에너지처럼 필요한 소재에 선택적으로 쓴다. 모든 몸에 같은 위아래 그라데이션을 넣지 않는다.

### 재질과 효과

- 털·나무·돌은 무광 중심, 꿀·보석은 제한된 광택, 마법·꽃가루는 국소 발광으로 구별한다.
- 유리·금속·얼음의 사용은 허용한다. 같은 스테이지의 소재 참조와 맞는 투명 범위·반사·면 처리를 사용한다.
- 눈과 주요 얼굴 면은 읽을 수 있게 남긴다. 전신 투명화, 전신 거울광, 전신 발광, 넓은 Bloom을 기본값으로 삼지 않는다.
- 효과를 꺼도 어떤 종인지, 대표 오브제가 무엇인지 알아볼 수 있어야 한다. 파티클은 몸 전체를 가리는 덮개로 사용하지 않는다.
- 고등급의 특별함은 먼저 큰 구조·소재·고유 행동으로 만든다. 발광 세기나 입자 수만 올려 등급을 구분하지 않는다.
- 중립 조명에서 먼저 완성하고 실제 낮·밤 및 스테이지 조명에서 확인한다. 신규 하나를 맞추려고 전체 색보정이나 기존 재질을 바꾸지 않는다.

## 5. 개성·오브제·희귀도·움직임

신규 캐릭터마다 다음을 문서에 남긴다: 존재와 소재의 조합, 성격, 큰 실루엣, 얼굴 비율, 대표 특징 1개, 보조 특징 1~2개, 대표 오브제의 연결 방식, 색의 역할, 짧은 대기 행동.

소품은 몸과 기능적으로 연결한다. 등 위에 올려놓은 장식만으로 개성을 대신하지 않는다. 예를 들어 도구라면 잡거나 움직이고, 껍질이라면 몸을 감싸며, 식물이라면 자라는 뿌리나 줄기의 연결이 보여야 한다.

같은 스테이지에서도 큰 형태·얼굴 비율·주색·대표 특징을 분산한다. 리그와 기본 몸체를 공유할 수 있지만 색만 바꾸거나 머리 장식만 교체한 결과를 완성된 신종으로 취급하지 않는다.

C/B도 얼굴과 대표 특징을 완성한다. 상위 등급은 더 명확한 고유 구조, 소재 대비, 독자적인 행동으로 단계가 올라감을 표현한다. 등급이 높아졌다고 눈 스타일이나 복셀 밀도를 다른 게임처럼 바꾸지 않는다. 모든 등급을 금색·왕관·오라로 구분하지 않는다.

SECRET 드래곤은 해당 스테이지의 요소를 종합한 고유 실루엣과 인상을 유지한다. 현재 확장 작업에서는 기존 SECRET 20종을 보존하며 추가 제작이나 리워크를 자동으로 실행하지 않는다.

대기 동작은 몸의 움직임 하나와 이에 따라오는 부속물 반응을 중심으로 정리한다. 모든 파츠를 독립적으로 흔들지 않는다. 형태 참조의 움직임을 그대로 복사하기보다 동작의 크기·속도·여유를 맞춘다. 장식 연출을 실제 재화·아이템·지형을 생성하는 기능으로 구현하지 않는다.

## 6. 알과 스테이지 요소에 적용하는 범위

알은 부화체의 대표 색·소재·문양 중 핵심 요소를 계승한다. 껍질의 큰 면을 남기고 모든 캐릭터 장식을 알 표면에 축소해서 붙이지 않는다. 알의 인상으로 어느 스테이지와 소재에 속하는지 읽히게 한다.

스테이지는 대표 소재, 큰 구조물, 반복되는 문양과 빛의 성격으로 구분한다. 장난감의 천과 블록, 화산의 무광 암석과 좁은 용암빛, 고철의 큰 교체 부품처럼 캐릭터와 환경이 같은 소재 표현을 공유한다. 배경의 디테일과 발광이 캐릭터의 얼굴·오브제와 경쟁하지 않게 한다.

이 가이드는 앞으로 제작할 알·스테이지 요소에도 적용한다. 이번 스타일 지정만으로 기존 알 크기·무게 공식, 기존 맵, UI, 드롭률, 재화, 성장곡선을 변경하지 않는다. 실제 변경 범위는 각각의 제작 작업 지시를 따른다.

## 7. 프로젝트 내부 레퍼런스 등록 절차

실제 프로젝트에서 이 가이드를 적용하는 작업자는 아래 절차를 수행한다. 엔진이나 디렉터리를 미리 가정하지 않는다.

1. 프로젝트의 기존 문서 구조와 레퍼런스 폴더, 아트 규칙, 캐릭터 목록, 기준 모델, 비교용 이미지, 렌더 설정을 읽는다. 실제로 존재하는 자료만 사용한다.
2. 같은 목적의 공식 스타일 문서가 있으면 그 문서를 갱신한다. 없다면 `docs/art/STYLE_GUIDE.md`를 권장 위치로 사용한다. 이 경로는 생성 제안이며 이미 존재한다고 가정하지 않는다.
3. 첨부 220종 MD는 프로젝트의 문서 관례에 맞는 위치에 원문 그대로 보관하고 공식 스타일 문서에서 연결한다. 과거 명령문을 다시 실행하지 않는다는 설명을 함께 남긴다.
4. 공식 스타일 문서와 같은 위치에 `REFERENCE_INDEX.md`를 만들거나 기존 레퍼런스 색인을 갱신한다. 중복되는 공식 문서를 여러 개 만들지 않는다.
5. 프로젝트에서 이미 공식으로 등록된 레퍼런스의 실제 경로와 역할을 색인에 연결한다. 지정 기록이 없는 자료는 후보로 구분한다. 확인되지 않은 모델이나 렌더를 확인했다고 기록하지 않는다.
6. 스테이지별로 형태 참조와 소재 참조를 연결한다. 캐릭터의 실제 ID를 기준으로 연결하고, 이름이 달라졌다고 원본 이름을 되돌리지 않는다. 신규 380종 문서의 `Rxx-xx` 표기는 문서 참조 번호이며 런타임 ID가 아니다.
7. 기존 제작 안내 문서나 README에 공식 스타일 가이드 링크를 추가한다. 별도 에이전트 지침 파일이 있다면 기존 구조를 유지하면서 아트 기준 링크만 연결하고 다른 지침을 덮어쓰지 않는다.
8. 신규 제작 작업을 시작할 때 공식 가이드 → 해당 스테이지 기준 → 지정 형태/소재 참조 → 개별 콘셉트 순서로 읽도록 제작 지시에 연결한다.

등록 정보에는 다음 필드를 포함한다.

| 필드 | 기록할 내용 |
| --- | --- |
| 참조 ID | 문서에서 유일한 식별자. 런타임 캐릭터 ID와 구분 |
| 상태 | 공식 / 후보 / 폐기 / 확인 불가 |
| 실제 경로 | 프로젝트 기준 상대 경로 또는 실제 자산 식별자 |
| 자료 종류 | 설계 문서 / 모델 / 이미지 / 재질 / 렌더 설정 |
| 스테이지·캐릭터 ID | 확인된 실제 연결. 미확인 값은 미확인으로 표시 |
| 담당 역할 | 형태 / 눈 / 색 / 소재 / 오브제 / 동작 / 조명 |
| 계승 범위 | 가져와야 하는 특징과 가져오지 않을 종별 특징 |

| 변경 정보 | 확인 가능한 리비전·파일 해시·갱신 기록 |

첨부 MD는 이미 사용자가 지정한 공식 자료다. 프로젝트 내부 색인을 작성하는 일과 모델 수정은 별개다. 자료만 확인할 수 있는 환경에서는 문서 연결까지 수행하고, 렌더를 검증할 수 없는 부분을 분명히 남긴다.

## 8. 신규별 제작 및 비교 기준

각 신규는 같은 스테이지의 **형태 참조 1개와 소재 참조 1개**를 연결한다. 두 역할을 잘 만족하면 같은 원본 캐릭터를 두 역할에 사용할 수 있다.

- 형태 참조에서는 눈의 블록 크기, 큰 덩어리의 단순화, 연결 파츠의 두께와 분할 수준을 가져온다. 참고 생물의 몸을 그대로 복제하지 않는다.
- 소재 참조에서는 색면의 분리, 색 변화 단계, 광택·투명·발광의 범위, 오브제의 면 처리를 가져온다. 모든 장식이나 팔레트를 그대로 가져오지 않는다.
- 해당 기준 모델을 찾지 못하면 MD의 설명을 따른다. 이 경우 ‘문서 기준 적용, 실제 자산 비교 미실시’로 기록한다.
- 신규 380종은 제작 문서에 지정된 760개 참조 연결을 사용한다. 이미 추가된 항목은 같은 ID로 외형을 수정하고 중복 생성하지 않는다.

비교는 같은 카메라, 중립 조명, 배경에서 원본 형태 참조·소재 참조·신규를 나란히 배치해 수행한다. 이어서 실제 게임의 낮·밤, 해당 스테이지, 도감 화면에서도 확인한다. 원본 크기와 도감 프레이밍은 별도로 확인하며 비율을 찌그러뜨리지 않는다.

64~96px 썸네일은 작은 화면에서 읽히는지 확인하기 위한 점검 조건이다. 원본 프로젝트가 이 해상도를 사용한다고 단정하지 않는다. 실제 UI 표시 크기가 확인되면 그 크기도 함께 점검한다.

| 확인 항목 | 통과 조건 |
| --- | --- |
| 같은 게임의 인상 | 신규만 눈·복셀 밀도·광택·파츠 두께가 다르게 튀지 않음 |
| 얼굴 | 눈·주둥이·표정이 작게 표시되어도 구별됨 |
| 형태 | 대표 실루엣과 오브제가 효과 없이 읽힘 |
| 종의 개성 | 색을 빼도 연결된 원본과 다른 종으로 구별됨 |
| 스테이지 개성 | 소재·구조·문양으로 같은 스테이지에 속함이 드러남 |
| 색과 재질 | 큰 색면과 필요한 대비가 유지되고 노이즈가 없음 |
| 파츠 | 대칭 기준과 연결 뿌리가 맞고 움직일 때 분리되지 않음 |
| 희귀도 | 등급 차이가 구조·소재·행동으로 보이며 효과에만 의존하지 않음 |
| 원본 보존 | 기존 원본 자산·이름·ID·수치·소유 데이터가 유지됨 |

확인 가능한 범위에서 비교 후 수정하고 나머지 제작을 진행한다. 이 가이드 자체는 별도 승인 대기를 추가하지 않는다. 완료 보고에서는 문서 등록, 모델 적용, 실제 렌더 비교의 완료 여부를 각각 사실대로 구분한다.

## 9. 후속 제작 지시에 붙일 공통 문장

> 프로젝트의 공식 아트 스타일 가이드와 레퍼런스 색인을 먼저 읽어라. 사용자가 지정한 `voxel-art-rework-220-characters.md` 및 프로젝트 내부의 공식 기준 자료를 따라 같은 복셀·눈·색면·파츠·재질 표현을 유지하라. 각 신규는 같은 스테이지의 형태 참조와 소재 참조를 연결하고, 고유 생물·소재·오브제·행동을 남겨라. 원본 220종은 보존하고, 이미 존재하는 확장 세트는 같은 ID의 외형만 수정하며, 없는 신규만 추가하라. 새 외부 레퍼런스로 공식 스타일을 대체하거나 첨부 원문의 과거 전체 리워크 지시를 다시 실행하지 마라. 실제 프로젝트 경로·측정값·비교 결과는 확인한 것만 기록하라.

## 10. 스테이지별 공식 표현 기준

아래 기준은 첨부 220종 MD의 캐릭터 설명을 바탕으로 정리했다. 이름은 참조 문서의 이름이며 현재 프로젝트의 표시 이름 변경을 지시하지 않는다. 실제 자산과 연결할 때는 기존 ID를 확인한다.

### 01. 몽글 초원

새싹이의 단순한 점눈과 짧은 얼굴, 꿀단지 곰의 굵은 몸과 하나의 소품, 무지개 나비의 큰 색 구획을 기준으로 한다. 꽃·잎은 크게 묶고 얼굴 위에 쌓지 않는다.

### 02. 장난감 왕국

단추곰의 큰 천 덩어리, 블록코끼리의 분절된 굵은 코, 종이배 펭귄의 큰 접힌 면을 기준으로 한다. 유리나 고무는 구슬고양이·풍선강아지의 제한된 표현 범위 안에서 구분한다.

### 03. 심해 산호숲

물방울 물개의 낮고 둥근 몸, 파도 가오리의 큰 날개 면, 산호거북의 큰 산호 세 갈래를 기준으로 한다. 진주·반투명 소재가 얼굴을 가리지 않게 한다.

### 04. 화산 대장간

숯병아리의 어두운 무광 몸과 좁은 불빛, 화로거북의 단순한 뚜껑, 모루두더지의 굵은 작업 도구를 기준으로 한다. 고밀도 균열과 전신 불꽃은 추가하지 않는다.

### 05. 유령 학교

지우개 햄스터의 넓은 볼과 큰 색 구획, 종이학의 굵은 접힌 면, 책가방 거북의 하나의 잠금쇠를 기준으로 한다. 글자와 낙서는 큰 문양 몇 개로 정리한다.

### 06. 네온 사이버시티

배터리 햄스터의 세 칸 잔량창, 택배너구리의 큰 함, 홀로그램 잉어의 불투명한 몸과 제한된 지느러미 효과를 기준으로 한다. 회로·간판은 화면을 읽을 만큼 큰 면으로 만든다.

### 07. 황금 사막왕국

모래여우의 큰 귀와 짧은 얼굴, 물병낙타의 둥근 혹과 하나의 물병, 작은 스핑크스의 큰 앞발을 기준으로 한다. 금색은 문양·테두리·소품에 집중한다.

### 08. 태초의 공룡섬

알껍질 공룡의 큰 머리와 작은 앞발, 조약돌 안킬로의 큰 갑판, 과일 익룡의 넓은 날개막을 기준으로 한다. 뼈·돌·깃털을 잔부품으로 세분하지 않는다.

### 09. 도깨비 달마을

복주머니 참새의 단순한 몸과 매듭, 청자두꺼비의 넓은 몸과 적은 돌기, 보자기 박쥐의 세 구획 천날개를 기준으로 한다. 단청·부적은 읽기 쉬운 큰 문양으로 정리한다.

### 10. 올림포스 신전

구름양의 큰 털 덩어리, 월계관 사자의 넓은 가슴, 대리석 그리핀의 큰 명암 면을 기준으로 한다. 금색·청동·구름 장식을 모든 부위에 동시에 붙이지 않는다.

### 11. 외계인 51구역

안테나 슬라임의 하나의 내부 구슬, 원반문어의 큰 껍데기, 별꽃 사마귀의 큰 꽃잎 날개를 기준으로 한다. 눈과 얼굴은 불투명하고 낯선 기관은 굵게 단순화한다.

### 12. 스팀펑크 공중도시

찻주전자 코끼리의 세 구간 코, 풍선고래의 큰 천주머니, 시계부엉이의 가슴 시계 하나를 기준으로 한다. 작동하는 큰 기어·관·천 면을 중심으로 구성한다.

### 13. 영원의 빙하

목도리 펭귄의 선명한 얼굴과 따뜻한 소품, 털북숭이 매머드의 넓은 털 층, 유리빙어의 불투명한 배와 투명 부위를 기준으로 한다. 얼음 디테일은 큰 판으로 표현한다.

### 14. 뒤죽박죽 꿈나라

베개강아지의 넓은 천 몸, 찻잔고양이의 드러난 얼굴, 별사탕 고슴도치의 큰 가시 다섯 개를 기준으로 한다. 불가능한 관계는 하나만 강조하고 얼굴은 단순하게 둔다.

### 15. 방사능 폐허

새싹들쥐의 작은 식물 하나, 깡통꽃게의 큰 통과 꽃, 온실사슴의 큰 유리판을 기준으로 한다. 녹·흙·오염은 큰 구역으로 제한하고 상처나 복잡한 노이즈로 만들지 않는다.

### 16. 곤충 소인국

꽃꿀벌의 넓은 줄무늬, 도토리 장수풍뎅이의 큰 뿔, 비단나방의 둥근 날개와 한 줄의 실을 기준으로 한다. 가는 다리와 실도 썸네일에서 읽히는 굵기로 만든다.

### 17. 고철 로봇행성

양철강아지의 큰 교체 부품 면, 자석문어의 굵은 팔 끝, 유압고릴라의 큰 피스톤 하나를 기준으로 한다. 리벳·전선·회로를 전신 표면에 흩뿌리지 않는다.

### 18. 은하수 천문대

혜성다람쥐의 세 구간 꼬리 색, 토성고양이의 하나의 비스듬한 고리, 은하수 고래의 하나의 큰 은하 띠를 기준으로 한다. 별점과 고리는 필요한 위치에만 둔다.

### 19. 공허의 틈

빈껍질 거북과 공백가오리의 두께 있는 빈 구조, 조각여우의 세 조각 꼬리, 경계의 사냥개의 큰 명암 구역을 기준으로 한다. 얼굴과 연결 뿌리는 온전하고 명확하게 만든다.

### 20. 창조주의 정원

첫새싹의 단순한 씨앗 얼굴, 흙빚는 곰의 큰 손과 하나의 점토, 계절나비의 네 큰 색 구획을 기준으로 한다. 생성 연출은 한 번에 하나의 작은 변화로 정리한다.

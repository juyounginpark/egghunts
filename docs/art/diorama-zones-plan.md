# 흩어진 소품에서 작은 디오라마로

2026-09-27 최신 사용자 방향을 적용한다. 개수 추가보다 군집, 높낮이, 큰 실루엣, 구역별 색과 국소적인 바닥 디테일을 우선한다.

## 공통 구성

- 지면·보조 소품·배경 풍경이 동일한 8개 존의 중심을 사용한다. 각 존은 대표물과 크기가 다른 보조물로 구성하며 사이에 빈 공간을 둔다.
- 3개 존은 +0.32, 1개 존은 -0.16의 장식용 지면 높이를 갖는다. 중앙 통로는 높이 0이다. 20스테이지는 길이에 맞춰 지형 구역 깊이를 늘린다.
- 평지 70%, 한 단 높이 20%, 쌓인 장식 10%를 구성 방향으로 삼는다. 실제 면적을 측정한 비율은 아니다. 2~3단 이상 높이는 통로의 계단 대신 책·블록·구조물의 쌓임으로 표현한다.
- 일반 랜드마크는 기존 배치 배율 0.95에서 1.33으로 키운다. 보조물은 한 존에서 크기·방향·간격을 다르게 한다.
- 이전의 길 양옆 반복 배경열은 제거하고, 같은 존에 큰 배경과 낮은 군락을 연결한다. 빈 바닥 전체에 소품을 균등하게 뿌리지 않는다.
- 접촉 피해·장식 충돌·감속은 없다. 플레이어·펫·알은 지면 높이를 공유한다. 자연 알과 보스의 중앙 구역은 평지다.

바닥 경계는 일부 존에만 러그 가장자리·종이·조각을 걸쳐 가린다. 낙서와 가루도 연필 장면 근처로 제한한다. 움직임은 기차역 깃발과 요새의 바람개비에 연결한다.

## 함께 요청된 접힌 UI

상단 정보를 접으면 좌측 64×64 패널에 낮/밤 아이콘과 잔여시간만 표시한다. 설명·진행 막대·계정·재화·속도 정보는 접힌 상태에서 숨긴다. 같은 패널을 누르면 다시 펼친다. 스테이지 진입 안내와 튜토리얼은 기존 동작을 유지한다.

자동 QA·스크린샷 검수·성능 측정은 실행하지 않는다. 배포 빌드와 실기기 확인은 별개다.

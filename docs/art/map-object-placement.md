# 스테이지별 20종 오브제와 배치 개정

2026-09-27 사용자 요청: 잡몹 제거, 공식 레퍼런스를 따른 각 스테이지 20종 오브제, 진로 방해 금지, 환경 장애물의 클라이언트 처리.

기준은 [공식 스타일 가이드](STYLE_GUIDE.md)의 6절·10절, [공식 레퍼런스 색인](REFERENCE_INDEX.md), [오브제 원문 400행](exploration-v2-catalog.json)이다. 이번에는 문서 기준을 적용했으며 새 실기기/렌더 비교를 수행했다고 보고하지 않는다.

- 큰 구조물 20개를 `src/exploration-landmarks.ts`에서 개별 조형했다. 굵은 복셀, 2~3단계 소재 색면, 넓은 열린 중심과 제한된 포인트색을 사용한다.
- `src/exploration-object-art.ts`의 20행별 ID를 유지한다. 주요 구조물은 후반 좌우에 두고 소품은 입구·중반·위험 구간 전후·후반의 네 묶음에 배치한다. 같은 크기의 등간격 행렬을 사용하지 않는다.
- 소품 후보 지점은 본길과 옆 우회로 보행면을 모두 피하도록 선택한다. 장식에는 새 충돌을 만들지 않는다. 알 자리 중앙은 낮은 둥지 조형만 사용하며 기존 선택 지름길 문은 계속 별도 관리한다.
- 바닥 역할은 일반 입체 소품을 눌러 재사용하지 않고 잎맥·조개 면·판재·매트·둥지 테두리로 별도 조형한다. 시계/기어/풍차의 움직임은 해당 부품 중심을 기준으로 한다.
- 잡몹은 화면뿐 아니라 로컬/서버 생성·전투에서도 제거했다. 환경 장치는 로컬 프레임 시계로 동작하고 서버에는 접촉 결과만 반영한다.

# 최신 개정: 장애물 없는 탐험 풍경

2026-09-27: 아래 이전 배치보다 이번 개정이 우선한다. 실제 20종 목록은 `src/exploration-scenery.ts`의 `SCENERY_KINDS`를 따른다. 기존 바닥·함정 항목을 장식으로 교체했고, 스피드 발판과 높아진 바닥은 제거했다.

각 맵은 대표 구조물과 19종 소품을 우선 배치하고, 식생은 최대 5개체, 일반 소품은 최대 2개체까지 빈 공간에 반복한다. 길 중앙을 비우고 좌우 군집의 크기·각도·간격을 달리한다. 모든 장식은 비충돌이다. 바깥 협곡 경계와 보스·알은 유지한다.

자동 렌더 검수나 성능 측정은 실행하지 않았다.

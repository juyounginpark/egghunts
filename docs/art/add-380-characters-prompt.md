# 기존 캐릭터 보존 · 스테이지당 30종 확장 프롬프트

현재 프로젝트의 기존 캐릭터를 그대로 유지하면서 새로운 종류를 추가하라. 이전의 ‘전체 리워크’ 지시를 다시 실행하지 않는다. 이 문서의 목표는 스테이지당 기존 11종에 신규 일반 캐릭터 19종을 더하여 총 30종으로 확장하는 것이다. 20개 스테이지 기준 기존 220종 + 신규 380종 = 총 600종이며, 기존 SECRET 드래곤 20종은 그대로 유지한다.

이 문서는 실제 프로젝트에 전달할 구현 지시와 신규 디자인 설계안이다. 실제 구현을 이미 마쳤다는 보고서가 아니다. 먼저 프로젝트를 확인하고 현재 엔진·데이터·아트 구조에 맞춰 끝까지 구현하라. Roblox는 참고한 게임의 맥락이며 현재 프로젝트의 엔진을 Roblox로 가정하지 않는다.

## 1. 최우선 원칙: 기존 것은 그대로

보존 대상은 현재 프로젝트에 존재하는 모든 기존 캐릭터와 소유 인스턴스다. 이전 기획 파일의 이름보다 현재 코드와 저장 데이터의 ID를 우선한다.

- 기존 이름, 표시 이름, ID, 스테이지 소속, 등급, 능력치, 생산량, 모델, 얼굴, 눈, 배색, 재질, 애니메이션, 전용 효과를 변경하지 않는다.
- 기존 SECRET 드래곤의 종류 수와 외형·이름·등급을 유지한다. 새 SECRET 드래곤은 추가하지 않는다.
- 기존 알의 모델·연결 대상·등급·저장된 무게와 크기 계산 규칙을 유지한다.
- 기존 모델을 새 디자인으로 덮어쓰기, 이전 버전으로 복원, 이름 다시 바꾸기, 등급 재배치, 삭제 후 재생성을 하지 않는다.
- 공통 모델 생성기·공유 재질·공유 리그를 수정해 기존 캐릭터까지 바뀌지 않게 한다. 필요한 경우 신규 전용 데이터·복제 재질·명시적인 신규 옵션을 추가하고 기존 기본값은 유지한다.
- 기존 모델의 대칭이나 디자인 문제가 보여도 이번 범위에서 고치지 말고 별도 목록으로만 남긴다.
- 현재 UI, 스테이지 배경, 셰이더, 낮·밤 주기, 재화 단위, 한 달 성장곡선은 이 작업을 이유로 리워크하지 않는다.

추가가 필요한 항목은 신규 캐릭터 데이터·모델·이름·도감 항목·기존 구조에 필요한 알 연결·획득 등록이다. 등급 내 신규 종류를 추첨하기 위한 풀 확장은 허용한다.

## 2. 개수와 등급 배분

| 등급 | 스테이지당 최종 목표 | 20스테이지 기준 목표 |
| --- | ---: | ---: |
| C | 8 | 160 |
| B | 7 | 140 |
| A | 5 | 100 |
| S | 4 | 80 |
| SS | 3 | 60 |
| SSS | 2 | 40 |
| SECRET | 1 | 20 |
| 합계 | 30 | 600 |

기존 캐릭터의 등급 분포를 아직 확인하지 않은 상태에서 고정된 새 배분을 덮어쓰지 않는다. 스테이지별로 기존 등급 수를 먼저 집계하라.

1. 기존 개수가 각 등급 목표 이하라면 ‘목표 수 - 기존 수’만큼 새 캐릭터를 배정한다.
2. 기존 등급 수가 목표를 넘으면 기존 캐릭터의 등급을 유지한다. 신규 배분만 조정하고 최종 차이를 보고한다.
3. 이 경우 비시크릿 등급의 부족분 d[r] = max(0, 목표[r] - 기존[r])을 구한다. 추가할 수 N을 부족분에 비례해 분배하고 정수 나머지는 소수 부분이 큰 순으로 배정한다. 동률은 C→B→A→S→SS→SSS 순으로 처리한다. 이 방법으로 총수와 기존 보존을 우선하며 ‘목표 배분 정확히 달성’이라고 허위 보고하지 않는다.
4. 실제로 한 스테이지에 11종이 있지 않다면 필요한 추가 수는 max(0, 30 - 실제 기존 종류 수)다. 19개 설계안에서 필요한 항목을 선택한다. 기존이 30종을 넘으면 삭제하지 말고 그 스테이지의 추가 적용을 보류하여 예외를 보고한다.
5. 현재 존재하는 보스나 추가 SECRET 등 별도 항목은 기존 분류를 보존한다. 수집 가능한 종류를 집계할 때 중복 레코드·스킨·개체별 무게를 새 종으로 세지 않는다.

아래 개별 프롬프트의 등급은 ‘권장 등급’이다. 현재 등급을 변경하라는 뜻이 아니다. 신규 캐릭터의 최종 등급은 실제 부족분에 맞추고 모델의 강조 수준도 최종 등급에 맞게 조절한다.

참고 배분: 기존 일반 10종이 C 3 / B 2 / A 2 / S 1 / SS 1 / SSS 1이라면 신규 19종은 C 5 / B 5 / A 3 / S 3 / SS 2 / SSS 1이다. 이 기존 분포는 예시이며 실제 데이터라고 가정하지 않는다. 아래 표는 이 예시를 기준으로 개성을 분산한 후보안이다.

## 3. 추첨과 경제 연결

- 기존 등급별 총 등장 확률을 유지한다. 먼저 기존 규칙으로 등급을 결정한 뒤 해당 스테이지·조건의 등급 내 캐릭터를 선택한다.
- 기존 풀이 균등 추첨이면 신규도 같은 등급의 동등한 후보로 등록한다. 기존이 가중 추첨이면 기존 캐릭터끼리의 상대 가중치를 유지하며 같은 기준으로 신규 가중치를 설정한다.
- 종류가 추가되면 동일 등급 내 기존 개별 캐릭터의 절대 확률은 낮아질 수 있다. 등급 총확률 보존과 개별 종류 확률 보존을 동시에 달성했다고 주장하지 않는다.
- 새 캐릭터를 넣기 위해 기존 SECRET의 총확률, 천장, 한정 조건, 낮·밤 조건을 변경하지 않는다.
- 신규 생산량·능력치는 같은 스테이지와 등급의 기존 분포 안에서 정한다. 신규라고 일괄 상위 성능을 부여하지 않는다.
- 조건별 기대 생산량을 비교하고 필요한 보정은 신규 데이터에만 적용한다. 기존 수치나 한 달 성장 목표를 몰래 조정하지 않는다.
- 스테이지 진입이나 돌파 조건에 30종 완수, 특정 신규 SSS 획득 등을 추가하지 않는다. 종류 확장은 선택과 장기 수집의 폭을 넓히는 용도다.
- 무게는 기존 생성·저장 함수를 사용한다. 새 외형 장식이나 후광을 알 크기 정규화 기준에 포함하지 않는다. UI·운반·부화에 연결할 때 기존 무게 비례 크기를 그대로 적용한다.
- 종별 알을 쓰는 구조라면 신규 종의 대표 색·오브제 1~2개를 알에 연결한다. 등급/스테이지 공용 알을 쓰는 구조라면 기존 공용 알에 신규 결과를 등록하고 380개의 별도 알을 억지로 만들지 않는다.

## 4. 신규 380종의 아트 공통 지침

- 기존과 함께 놓았을 때 같은 게임의 캐릭터처럼 보이도록 블록 단위·면 처리·눈의 표현·조명을 맞춘다.
- 기존 스타일과 맞추기 위해 기존 모델을 수정하지 않는다. 신규 쪽의 디테일 밀도·재질·채도를 맞춘다.
- 몸통은 간단한 큰 덩어리로 만들고 귀·목·꼬리·뿔·날개는 연결점을 기준으로 기울여 흐름을 준다. 모든 파츠를 축에 평행하게 쌓지 않는다.
- 몸 형태, 얼굴 비율, 주색, 대표 오브제 중 최소 두 항목이 기존 같은 스테이지 캐릭터와 확실히 다르게 보이게 한다. 단순 재색칠과 머리 장식 교체는 새 종의 완성으로 처리하지 않는다.
- 공통 얼굴판을 반복하지 않는다. 작은 점눈을 기본으로 눈 간격·높이·코 길이·볼 너비를 종에 맞춰 정한다.
- 좌우 눈, 다리, 귀·날개 뿌리를 중심선 기준으로 정렬한다. 물건을 든 자세나 비대칭 껍질은 의도적으로 설계하고 기록한다.
- 이름은 익숙한 소재와 생물 조합을 중심으로 읽기 쉽게 만든다. 모든 이름에 콩·뽀·꼬를 붙이거나 최강·전설·궁극 같은 접두사를 반복하지 않는다.
- 모델은 고정 50³·24³ 박스에 억지로 넣지 않는다. 생물별 비율과 화면에서의 식별을 우선한다.
- 색은 몸·보조·포인트 역할을 나누고 소재에 맞춘 2~3단계 색 변화를 사용한다. 무작위 복셀 얼룩과 전신 무지개 발광을 피한다.
- C/B도 귀여운 얼굴과 분명한 오브제를 갖춘다. S/SS/SSS는 큰 구조·소재·행동으로 차이를 만들며 효과를 끈 상태에서도 매력적이어야 한다.
- SSS는 해당 스테이지의 기존 SECRET 드래곤과 다른 수집 목표다. 새 캐릭터에 SECRET 표시·전용 드래곤 연출·동일한 상징 구조를 복사하지 않는다.
- 이하 행동과 소품 효과는 대기 연출이다. 전투·수익·날씨·지형 변화·아이템 생성을 자동으로 새 기능으로 구현하지 않는다.
- 신규 380종을 모든 장면에서 한꺼번에 생성하거나 애니메이션 갱신하지 않는다. 기존 로딩 구조에 맞춰 현재 스테이지·보유 목록·보이는 도감 항목에 필요한 모델만 준비하고 캐시를 재사용한다.
- 신규 복셀 모델은 현재 렌더러에 맞는 메시 병합·인스턴싱·공유 지오메트리를 활용한다. 재질 공유 중 개별 색을 바꾸어 기존 캐릭터까지 변하지 않게 한다.
- 신규 이펙트는 모바일 품질 설정에 따라 줄일 수 있게 만들고, 줄이거나 꺼도 얼굴·오브제·큰 윤곽이 유지되게 한다. 실제 실행 환경 없이 프레임 성능을 검증했다고 보고하지 않는다.

## 5. 구현·보존 확인

1. 기존 캐릭터 ID와 연결 데이터, 핵심 수치, 자산 참조를 기준 스냅샷으로 확보한다. 현재 작업 파일을 덮어쓰지 않는다.
2. 새 ID는 기존 규칙을 따르되 사용된 ID를 재활용하지 않는다. 아래 ‘01-N01’ 같은 번호는 문서용 식별자이며 기존 런타임 ID를 뜻하지 않는다.
3. 이름 또는 모티브 충돌이 발견되면 신규 후보의 이름·외형만 조정한다. 기존 항목은 그대로 둔다.
4. 누적 재실행 시 중복 생성되지 않도록 신규 ID와 등록 상태를 기준으로 갱신한다.
5. 신규 생성기 분기를 기존 항목에 적용하지 않는다. 공유 변경이 필요한 경우 기존 입력의 결과가 동일함을 확인한다.
6. 도감·검색·획득 알림·부화 결과에 신규 항목을 연결한다. 신규 항목이 마지막의 한 페이지에서 잘리거나 기존 슬롯을 대체하지 않게 한다.
7. 신규 모델의 기본 크기에서 발 접지·운반 위치·얼굴 시인성·관통을 확인한다. 작은 썸네일과 실제 플레이 크기에서 기존과 나란히 비교한다.
8. 스테이지마다 대표 모델을 먼저 렌더링하여 스타일을 맞춘 후 나머지에 적용하되, 대표 모델 몇 개만 만든 상태를 완료로 보고하지 않는다. 이미 허용된 작업 범위에서 단계적으로 계속 진행한다.
9. 기존 세이브 로드 후 보유 캐릭터·알·무게·수치·ID가 유지되는지, 기존 외형과 새 캐릭터 등록이 함께 정상인지 확인한다.
10. 최종 보고에는 실제 기존/신규/총수, 등급별 수, 미매핑·예외 항목, 실제 렌더링 비교, 실행한 검증과 미실행 항목을 구분한다.

## 완료 조건 다시 확인

- 기존 목록 220종이 실제 프로젝트에서도 일치한다면 기존을 그대로 유지하고 신규 380종을 추가해 600종으로 만든다.
- 일반 580종과 기존 SECRET 드래곤 20종이 기본 목표다. 기존 실제 수가 다를 때는 보존 규칙과 실제 집계를 우선한다.
- 신규는 모두 별도 캐릭터 ID이며 스킨·색 변형·무게 개체 수로 380종을 채우지 않는다.
- 본문의 권장 등급은 후보 설계용이다. 실제 최종 등급표는 기존 수를 확인한 뒤 부족분에 맞춰 만든다.
- 기존 캐릭터의 이름·등급·외형·능력치·저장 데이터를 수정해서 배분을 맞추지 않는다.
- 신규 이름이 실제 프로젝트의 다른 기존 캐릭터와 겹치면 신규 이름과 필요한 디자인만 수정한다.
- 설명문과 도감 카드만 추가한 상태, 같은 모델에 색만 바꾼 상태, 기존 모델을 신규로 복제한 상태를 완성으로 보고하지 않는다.
- 실제 모델, 데이터 등록, 획득 경로, 알 연결, 저장 호환성, 화면 식별을 함께 확인하고 완료한 범위를 정확히 보고한다.

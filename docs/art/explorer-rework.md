# 탐험가 외형 리워크 계획

기존 ID·고정 뼈대·충돌·세이브는 유지한다. 공통 아트 기준의 큰 복셀 덩어리, 무광 색면, 대표 실루엣 하나를 따른다. 의상별 차이를 작은 장식 개수로 만들지 않는다.

## 헤어와 가방

- 헤어 18종은 앞머리 길이뿐 아니라 정수리 높이, 좌우 부피, 뒷머리 길이, 묶은 위치가 다르다. 곱슬은 계단형 큰 덩어리, 생머리는 평평한 띠, 웨이브는 서로 어긋난 두 구간으로 구분한다.
- 모자는 정수리 돌출부를 낮춘 전용 배치로 사용한다. 헬멧 안에는 짧은 머리만 표시하되 저장된 헤어 선택은 바꾸지 않는다.
- 긴 머리는 어깨 바깥쪽으로 갈라져 가방 중앙을 비운다. 포니테일은 목 뒤에서 멈추거나 옆으로 흐르게 하며 몸통·가방을 관통하지 않는다.
- 탐험 가방: 납작한 가죽 플랩과 잠금끈. 캠핑: 세로 배낭과 하단 침낭. 알: 계단형 둥근 바구니와 밝은 알 덮개. 우주: 두 산소통과 연결판. 숲: 아래 넓은 주머니와 접힌 잎 덮개. 바다: 롤탑과 옆 물병. 동물: 귀와 둥근 바닥. 미니: 작은 비대칭 사각 가방.

## 겹침 방지

- 원본 몸통의 가방·의상을 제거하고 같은 뼈대 좌표에 새 몸통을 구성한다. 기존 표면 위에 전체 의상을 다시 씌우지 않는다.
- 정렬된 상자들은 외부에 드러나는 면만 만든다. 같은 평면의 겹침은 뒤에 정의한 파츠 한쪽만 남긴다. polygonOffset이나 투명도로 숨기지 않는다.
- 얼굴 무늬는 머리 표면, 표정 파츠, 안경 순으로 깊이를 분리한다. 같은 위치의 밴드·스티커는 중복 표시하지 않는다.
- 옷장 내부는 속이 빈 프레임으로 만들고 선반/접힌 옷/문을 서로 다른 공간에 배치한다. 벽 장식은 벽 앞, 러그는 바닥 위에 명확한 두께를 둔다.
- 준비실은 왼쪽 거울·수납, 오른쪽 행거·스툴, 뒤쪽 창문·지도 구도로 정돈하고 캐릭터 회전 공간을 비운다.

## 확인 범위

자동 QA·스크린샷·검증용 빌드는 별도 요청 전 실행하지 않는다. 회전·걷기·배트·탑승에서의 모든 조합 및 실기기 깜빡임은 미확인으로 기록한다. 배포 빌드 결과는 시각 품질 확인과 구분한다.

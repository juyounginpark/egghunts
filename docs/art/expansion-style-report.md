# 공식 스타일 적용 기록 — 2026-09-27

## 적용 범위

- 사용자 제공 `voxel-official-art-style.md`를 [STYLE_GUIDE.md](STYLE_GUIDE.md)로 등록했다. 수정 제작 지시는 [expansion-style-prompt.md](expansion-style-prompt.md)에 원문 그대로 보관했다.
- 기존 원본 설계와 현재 모델·재질·렌더 설정을 [REFERENCE_INDEX.md](REFERENCE_INDEX.md)에 연결했다. 380종의 형태/소재 참조 760개는 현재 카탈로그의 stageId/slot을 통해 실제 원본 모델 196개에 매핑했다. 문서 R 번호와 영구 ID를 구분하고 파일 해시·단위·눈 높이·파트 수를 기록했다.
- 변경 대상은 확장 ID 321~700의 모델·설계·썸네일과 신규 전용 애니메이션이다. 원본 ID 0~320, 카탈로그 ID/이름/등급/능력치, 저장·무게·알·확률·경제 코드는 수정하지 않았다.
- 스테이지당 30종, 스테이지 전체 600종, 이전 도감/주간 보상을 포함한 701종을 유지한다. 이번 작업에서 새 종을 중복 등록하지 않는다.

## 시각 표현 변경

- 미세한 구형 계단을 큰 평면과 잘린 모서리로 바꿨다. 같은 생물의 원래 길이·폭·팔다리·대표 오브제는 남기고 면 처리 수준을 단순화했다.
- 신규 모델의 단위는 지정 형태 참조의 실제 `unit` 값을 사용한다. 현재 연결된 원본은 21.6이다. 모든 모델을 정해진 정육면체 박스에 맞춘 것은 아니다.
- 작은 점눈을 머리의 자식 파트로 유지한다. 대표 다람쥐의 귀는 둥근 형태로, 꼬리와 밤송이는 갈색/적갈색으로 조정했다. 앵무조개는 아이보리 나선 껍질과 청색 얼굴, 두 구역의 자개색, 짧은 촉수로 정리했다.
- 지정 소재 참조의 무광/광택/금속 계열을 적용한다. 기존 전역 셰이더·공유 재질은 바꾸지 않았다. 유리 표현은 일부 소품/껍질에 제한하고 몸통·머리·눈은 불투명하게 유지한다.
- 모든 몸의 밑부분을 일괄 어둡게 하던 색띠를 없애고 꼬리·껍질·갈기 등 소재 방향에만 보조 명암을 둔다.
- 대기 동작은 주동작 하나와 지연된 귀·꼬리·날개 반응으로 묶었다. 소품과 몸이 각각 독립된 주기로 끊임없이 흔들리던 강도를 줄였다. 기존 펫 애니메이션은 건드리지 않았다.
- 단순화 과정에서 모양이 같아진 기와거북·별지도 거북·리벳참새·얼음콩 생쥐는 지붕 끝·지도/방향표·철판/리벳·콩 모양 소품의 기하 구조를 따로 조정했다.

## 비교 기록과 중단 범위

사용자 제공 문서가 처음에는 비교·보존 검사를 요청하여 대표 3종(ID 323/370/643)을 같은 카메라·중립 및 어두운 조명으로 실제 렌더링했다. 각 비교 행은 지정 형태 원본 / 지정 소재 원본 / 신규이며, 256px과 80px 축소를 함께 배치했다. 대표 중립 비교 이미지는 직접 확인했다. 어두운 조명은 검수용 조건이며 실제 스테이지 야간을 측정한 것이 아니다.

이후 사용자가 **“검수 ㄴㄴ”**라고 지시하여 전체 비교·검사 작업을 중단했다. 전체 비교 렌더·실제 게임 낮/밤 검수·도감 검수·검증 빌드를 추가 실행하지 않는다. 변경 후 전체 검수 통과로 보고하지 않는다.

중단 전 보존 검사에서는 신규 기하 중복 4쌍이 보고되었다. 해당 소품 기하는 수정했지만 사용자 지시에 따라 재검사하지 않았다. 전체 검사 성공 기록은 없다. Vite 파일 감시 초기화 지연은 일회성 제작/검수 서버의 watch/HMR을 끄는 방식으로 처리했으며 게임 실행 설정은 바꾸지 않았다.

게임에서 사용하는 PNG 380개는 `node scripts/render-expansion.mjs --assets-only`로 제작한다. 이 모드는 비교판 생성·기하/애니메이션 판정·QA 결과 저장을 실행하지 않는다. 기본 검수 명령과 기준은 수동 실행용으로 유지했다.

이전 작업의 `artifacts/expansion/*-audit.json`은 이번 최종 스타일 변경의 통과 근거로 사용하지 않는다. 실기기 FPS·전체 성능 예산도 이번에 재측정하지 않았다.

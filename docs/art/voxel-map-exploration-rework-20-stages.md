# 20개 스테이지 탐험·구조물·장애물·배트 지형 리워크 구현 프롬프트

이 문서 전체를 실제 게임 프로젝트를 열어 둔 Codex에 전달한다. 문서에 적힌 수치와 구조는 이번 작업의 설계 시작값이며, 현재 프로젝트를 측정하거나 구현을 완료했다는 의미가 아니다.

## 0. 수행할 작업

현재 게임의 1~20 스테이지를 아래 설계에 맞춰 실제로 리워크하라. 기존 엔진, 맵 생성 방식, 플레이어 이동, 배트 넉백, 알 획득·운반, 보스, 멀티플레이어 구조를 먼저 읽고 해당 구조 안에서 구현하라. Roblox는 아이디어의 출처이며 현재 엔진을 Roblox나 Unity로 가정하지 않는다.

목표 경험은 **빈손으로 안쪽까지 탐험 → 후반의 보스와 알자리 발견 → 끝부분에서 알 획득 → 알을 들고 입구 방향으로 귀환**이다. 초등학교 3학년이 화면을 보고 이해할 수 있게 한다. 이동, 기다리기, 기존 배트 사용, 가끔 인터랙트 한 번이면 충분해야 한다.

기획 문서 작성이나 장식 몇 개 추가로 끝내지 말고 실제 지형·구조물·충돌·장애물·보스 위치·알 생성 위치·왕복 경로에 적용하라. 현재 프로젝트 접근이나 실행이 불가능하면 확인 가능한 작업과 미실행 범위를 구분하고 실제 구현했다고 보고하지 않는다.

### 확정된 요구사항

1. 1~5스테이지는 무난하게 탐험하고 수집하는 구간이다. 본격적인 환경 장애물 난이도는 6부터 오른다.
2. 난이도는 경로와 장애물 배치로 올린다. 빠른 반응, 점프, 복잡한 퍼즐, 긴 설명문을 요구하지 않는다.
3. 모든 맵에 배트로 상대를 밀어 장난칠 수 있는 **대표 지형을 정확히 1곳** 설계한다. 기존 배트 사용 가능 범위를 이 구역으로 제한하라는 뜻은 아니다.
4. 트롤 지형은 1~5에도 존재한다. 초반에는 얕은 물·볼풀·매트 등으로 밀려나 몇 걸음 돌아오는 정도다.
5. 멀티플레이어가 함께 움직일 수 있는 넓은 길을 만든다. 몸으로 통로를 막는 현상과 배트 넉백을 구분한다.
6. 보스는 주동선 후반 60~85%, 알 생성 장소는 끝부분 85~100%에 배치한다.
7. 오른쪽 아래 인터랙트 버튼이 있다고 가정한다. 알 운반 중에는 환경 인터랙트를 사용할 수 없다.
8. 알을 들고도 모든 귀환·우회·트롤 착지 복귀 경로를 이동 입력만으로 통과할 수 있어야 한다.
9. 길 열기는 05·08·14·17의 선택 지름길에 각각 한 번만 사용한다. 본길은 처음부터 통행 가능하다.
10. 중간 샛길에는 전망, 드래곤 흔적, 지름길을 두고 알 생성은 후반으로 모은다. 숨은 알자리도 후반 샛길에 둔다.

## 1. 변경 범위와 공식 아트 기준

`voxel-official-art-style.md`, 프로젝트의 공식 스타일 가이드 및 레퍼런스 색인을 먼저 읽는다. `voxel-art-rework-220-characters.md`는 시각적 원전으로 참고한다. 원전에 포함된 과거 캐릭터 전면 리워크·이름 교체 명령은 재실행하지 않는다.

이번 사용자의 명시적 요청은 **맵 지형과 배치 리워크**다. 이전 문서의 ‘해당 작업에서 맵을 변경하지 않는다’는 범위 제한은 이번 맵 작업에 적용하지 않는다. 기존 캐릭터 원형을 보존하는 아트 기준은 계속 유지한다.

### 수정할 항목

- 20개 스테이지의 지형, 길, 경사로, 건물, 다리, 배경 구조물, 충돌체, 카메라 가림 처리.
- 환경 장애물의 표시·작동·피격 영역과 공용 상태 연결.
- 기존 배트 넉백으로 재미가 생기는 지형과 착지·복귀 경로.
- 기존 보스의 배치 위치, 해당 위치를 사용하는 활동 범위·귀환점·탐색 경로.
- 기존 알 생성기의 위치·바닥 앵커와 후반 분산 배치. 기존 스폰 조건은 유지한다.
- 4개 선택 지름길의 환경 인터랙트와 공용 개방 상태.

### 보존할 항목

- 기존 캐릭터·보스·알의 ID, 종류, 이름, 모델, 등급, 소유 데이터. 신규 캐릭터 제작이나 380종 추가는 이 작업에 포함하지 않는다.
- 스테이지 ID, 해금 순서, 기존 보스 수와 종류. ‘보스’와 ‘수집 가능한 SECRET 드래곤’을 같은 항목으로 임의 통합하지 않는다.
- 알 생성 총량·주기·등급 확률·중복 규칙, 보스 처치와 알 획득의 기존 관계.
- 알 무게와 크기 계산, 배트의 기본 피해·사거리·쿨다운·강도·알 강탈 규칙.
- 한 달 성장곡선, 재화 단위, 수입, 레벨 성장, 낮·밤 길이, 기존 출구와 반납 규칙.
- 알 운반 중 배트 사용 가능 여부도 기존 규칙을 유지한다. 환경 인터랙트 금지와 배트 사용 금지를 같은 조건으로 합치지 않는다.

연속 넉백 방지가 기존에 있다면 재사용한다. 없다면 이번 설계의 복귀 보호를 위해 최소한으로 추가하고 변경 내용을 보고한다. 나머지 전투·경제 규칙은 맵에 맞춘다는 이유로 재설계하지 않는다.

### 구조물의 시각 규칙

- 큰 복셀 덩어리, 읽기 쉬운 넓은 면, 명확한 소재 구분을 유지한다.
- 뿌리·나뭇가지·파이프·다리 아치는 굵은 파츠를 기울이고 연결해 곡선처럼 보이게 만든다. 모든 오브제를 같은 정육면체 크기로 만들지 않는다.
- 주색·보조색·포인트색의 역할을 나누고 2~3단계 색 변화로 깊이를 준다. 무작위 복셀 노이즈, 전신 발광, 전역 채도 증가로 디테일을 대신하지 않는다.
- 걷는 바닥, 위험 영역, 배경 장식은 형태·높이·재질로 구분한다. 색 하나에만 의존하지 않는다.
- 초원의 풀, 장난감의 천과 블록, 화산의 암석과 철, 학교의 나무와 종이처럼 스테이지마다 대표 소재가 달라야 한다.
- 실제 위험이 없는 길을 용암처럼 보이게 칠하지 않는다. 화산의 안전한 착지점은 분명한 검은 숯더미로, 위험한 용암은 밝고 흐르는 외곽 영역으로 구별한다.
- 큰 벽·나무·천장·알이 플레이어나 바닥 경고를 가리지 않게 한다. 기존 카메라에 맞춰 벽 높이, 잘린 단면, 선택적 가림 완화를 사용한다.
- 성능을 위해 반복 블록·재질·장식은 프로젝트의 기존 재사용 방식을 사용한다. 장식 복셀 하나마다 동적 물리 오브젝트를 만들지 않는다.

공식 문서를 읽을 수 없더라도 위 핵심 규칙으로 진행하되, 실제 원본 모델과 비교했다고 주장하지 않는다.

## 2. 공통 맵 구조와 치수 기준

### 2.1 길의 진행률

아래 백분율은 월드 좌표의 한 축이 아니라 **입구에서 알자리까지 이어지는 본길의 누적 진행률**이다. 기존 맵 크기를 그대로 백분율 좌표에 끼워 넣지 말고 실제 걷는 길을 기준으로 배치한다.

| 진행 구간 | 공간 | 배치 원칙 |
| --- | --- | --- |
| 0~15% | 입구·방향 확인 공간 | 출구 방향과 후반 랜드마크를 알아볼 수 있다. 출발 직후 함정이나 트롤 지형에 들어가지 않는다. |
| 15~60% | 탐험·장애물·교차 동선 | 대표 트롤 지형 1곳, 편한 우회로, 중간 전망과 흔적을 배치한다. |
| 60~85% | 보스 활동 공간 | 기존 보스를 후반에 배치하고 주변에 회피·관찰 공간을 둔다. |
| 85~100% | 알자리·후반 숨은 장소 | 기존 알 생성 지점을 분산 배치한다. 여기서 알을 얻고 돌아간다. |

알 획득 후 보스 공간의 측면 통로를 거쳐 중반의 원래 길로 합류한다. 맵 끝에서 입구로 바로 보내는 새 포털은 만들지 않는다. 중반에서 들어오는 사람과 돌아오는 사람이 만날 수 있어야 한다.

보스 처치가 필요한 기존 게임이라면 측면 통로가 그 조건을 우회하는 새 획득 수단이 되어서는 안 된다. 기존 처치·소유·해금 판정과 길의 물리적 통행을 별도로 유지한다. 트롤 낙하나 샛길로 알 획득 조건을 건너뛰게 만들지 않는다.

### 2.2 공통 상대 치수

`P`는 현재 기본 플레이어의 지면상 충돌 지름이다. 실제 코드를 읽어 확인하고, 미터·stud·Unity unit 등 특정 엔진 단위로 미리 가정하지 않는다. 아래 치수는 블록아웃 시작값이다. 실제 최대 접속 인원과 큰 알의 시야를 고려해 넓힐 수 있다.

| 구조 | 권장 시작 치수 |
| --- | --- |
| 기본 본길 | 폭 6~8P |
| 쉬운 우회로 | 폭 5~7P, 중앙 지름길보다 완만하고 가장자리 보호가 명확함 |
| 대표 트롤 지형 | 폭 5~6P, 길이 8~14P. 한 명이 전부 막을 수 없는 크기 |
| 안전한 대기 장소 | 최소 7P × 7P부터 시작, 실제 인원에 맞게 확장 |
| 트롤 착지 공간 | 최소 8P × 8P부터 시작, 실제 넉백 도달 범위 전체를 받아줄 만큼 확장 |
| 복귀 통로 | 폭 4~6P 이상. 점프 없이 이동 가능한 경사·계단 |
| 보스 공간 | 20~28P 폭부터 시작하고 실제 보스 몸체와 공격 범위에 따라 확대 |
| 보스 측면 귀환 통로 | 최소 6P 폭부터 시작. 한쪽이 혼잡하면 돌아갈 여지가 있음 |
| 후반 알 공간 | 18~26P 폭부터 시작, 3~5개 배치 구역으로 분산 가능 |

3~5개 알 배치 구역은 추가 알 생성 개수를 뜻하지 않는다. 기존 생성 예산을 여러 위치 앵커에 분산하는 공간 구성이다.

초반 트롤 지형은 0.25~0.75P 정도의 낮은 단차부터 시험한다. 후반도 높이만 키우지 말고 복귀 길의 굴곡과 길이로 차이를 만든다. 계단은 보이는 계단 형태와 실제 이동용 완만한 충돌면을 구분할 수 있다. 점프 입력이나 자동 점프 연타가 필요한 단차를 만들지 않는다.

모든 길의 길이와 장애물 간격은 **합법적인 가장 느린 알 운반 상태**에서도 이동 가능한지 확인해 조정한다. 맵 리워크를 이유로 플레이어 기본 속도나 무게에 따른 속도 규칙을 일괄 변경하지 않는다.

### 2.3 탐험의 보상

- 입구에서 큰 나무, 성, 화로, 천문대 돔처럼 후반 목적지의 윤곽이 보인다.
- 중반 샛길은 바로 옆에서 입구를 볼 수 있게 한다. 픽셀 단위 틈이나 벽 뒤 비밀 버튼 찾기를 요구하지 않는다.
- 중반에는 전망, 드래곤의 발자국·문양·벗겨진 비늘 같은 시각적 흔적, 선택 지름길을 둔다. 이런 장식에 새 재화나 능력치를 자동 추가하지 않는다.
- 일반·희귀·SECRET 관련 실제 알 생성 위치는 후반에 둔다. 기존 SECRET 조건이 별도라면 그 조건은 유지하고 알자리와 접근 공간만 후반으로 옮긴다.
- 후반 숨은 장소는 빛이 새는 입구, 큰 틈, 이어지는 발자국처럼 눈에 보이는 힌트를 가진다. 찾았다고 SECRET 획득을 확정하지 않는다.

## 3. 난이도와 환경 장애물

| 구간 | 구성 | 실패 비용과 읽기 쉬움 |
| --- | --- | --- |
| 01~05 | 넓은 본길, 환경 장애물 0~1종, 짧은 우회로 | 새 환경 요소에 맞아도 잠깐 감속하거나 가까이 밀리는 정도. 새 환경 피해·낙사·알 소멸을 추가하지 않는다. |
| 06~08 | 큰 장애물 한 종류, 충분한 대기 공간 | 움직임을 보고 기다렸다 통과한다. 기본 운반 속도로 피할 시간이 있다. |
| 09~12 | 한 종류의 장애물을 위치를 달리해 배치 | 짧고 위험한 길과 조금 긴 편한 길 중 선택한다. |
| 13~16 | 두 종류까지, 서로 떨어진 구간에 배치 | 하나를 통과한 뒤 안전한 공간에서 다음을 본다. |
| 17~19 | 두 종류까지, 길이와 방향을 다양화 | 경고 시간을 줄이지 않고 안전 구간을 연결해 연속 통과한다. |
| 20 | 이전에 배운 두 종류를 순서대로 사용 | 새로운 조작 없이 종합한다. 한 화면 전체를 동시에 공격하지 않는다. |

초반의 낮은 실패 비용은 이번에 만드는 환경 요소에 관한 규칙이다. 기존 보스 공격이나 배트의 알 강탈 규칙을 무단으로 비활성화하지 않는다. 초반 보스는 위치와 넓은 회피 공간으로 부담을 줄인다.

### 피할 수 있는 경고

- 분출·낙하형: 바닥 표시와 물체의 흔들림을 먼저 보여주고 실제 작동한다. 경고 없이 활성화하지 않는다.
- 이동형: 공·로봇·유령이 충분히 먼 곳부터 보이며 정해진 경로로 이동한다. 플레이어 바로 옆에 생성하지 않는다.
- 경고 시간은 2.0~2.6초부터 시험한다. 빠르게 보인다는 이유로 후반에서 계속 줄이지 않는다.
- 실제 최소 경고는 위험 구역 탈출에 필요한 거리 / 가장 느린 정상 운반 속도에 입력·네트워크 지연과 판단 여유를 더해 잡는다. 위 예시보다 길어야 하면 늘린다.
- 주기형은 경고 → 작동 → 충분한 휴식 순서를 유지한다. 휴식 중 운반자가 통과할 수 있어야 한다.
- 부채꼴·원·빈칸 등 실제 피격 범위와 표시를 일치시킨다. 표시 밖에서 맞거나 장식 파티클에 피해 판정이 붙지 않게 한다.
- 맵 환경 피격은 기존 체력·피격 무적 처리와 연결한다. 한 번 지나가는 물체가 프레임마다 중복 피해를 주지 않는다.
- 6부터 환경 피해를 사용하더라도 기존 피격 체계를 재사용하고 최대 체력을 일격에 지우는 값을 기본값으로 쓰지 않는다.
- 안전한 통과 시점이 항상 존재해야 한다. 서로 다른 장애물이 한 출구를 번갈아 영구 봉쇄하지 않도록 주기를 확인한다.

## 4. 배트 트롤 지형 공통 규칙

배트로 다른 플레이어를 밀어 물·볼풀·젤·아래층 길·반대 벨트로 보내는 행동은 의도된 재미다. 공격 가능한 범위를 대표 지형으로만 축소하거나 전체 맵을 비전투 구역으로 바꾸지 않는다.

각 맵의 15~60% 구간에 대표 지형 1곳을 둔다. 같은 맵에 이와 동등한 낙하 함정을 여러 개 추가하지 않는다. 별도 전망대나 계단 가장자리는 난간·턱·연속 지형으로 보호해 두 번째 필수 트롤 병목이 되지 않게 한다.

- 지름길을 고르면 배트에 밀릴 위험을 감수한다. 옆의 편한 우회로는 처음부터 사용할 수 있다.
- 1~5는 맞아도 가까운 곳으로 돌아오는 정도, 후반은 아래층을 따라 조금 돌아오는 정도다. 장시간 행동 불능이나 맵 처음으로의 강제 초기화를 주된 벌로 사용하지 않는다.
- 실제 배트의 최대 정상 넉백을 측정해 착지판과 경계를 배치한다. 문서의 작은 착지판을 그대로 두고 배트 강도를 임의로 줄여 맞추지 않는다.
- 착지판은 안전한 바닥·해초·숯·매트·그물처럼 눈에 보이게 만든다. 겉으로 열린 공간에 근거 없는 보이지 않는 벽을 세우지 않는다.
- 착지 후에는 걸어서 복귀한다. 알 내려놓기, 수영 버튼, 점프, 사다리 인터랙트, 승강기 호출을 요구하지 않는다.
- 얕은 물·초록 젤·진흙은 제한된 감속 구역이다. 감속을 무한 중첩하거나 운반 속도를 0으로 만들지 않는다.
- 기존에 없는 연속 넉백 방지를 추가해야 하면 약 1.2~1.8초를 시작값으로 시험한다. 이는 연속 강제이동 방지이며 별도의 전투 무적이나 알 보호를 임의 추가하는 지시가 아니다.
- 착지 지점과 복귀 첫 구간을 환경 함정에서 분리한다. 같은 자리에서 다시 공허로 떨어지는 무한 반복을 막을 만큼 넓은 바닥을 둔다.
- 일반 플레이어 몸 충돌 때문에 서 있는 한 명이 길을 막지 않게 한다. 접촉 충돌과 배트가 적용하는 강제이동은 구분한다.
- 큰 알의 시각 크기를 플레이어 간 밀기 도구로 사용하지 않는다. 기존 알 충돌·운반 규칙을 확인하고 바닥 경고와 상대 위치를 읽을 수 있는 공간을 확보한다.

알을 맞아 떨어뜨리는지, 빼앗을 수 있는지는 기존 규칙을 유지한다. 기존 규칙으로 떨어진 알은 해당 지형의 접근 가능한 바닥에 남아야 하며, 볼풀 속이나 지형 아래로 영구 소실되면 안 된다. 이미 발생한 드롭을 새 복귀 처리로 취소하거나 복제하지 않는다.

## 5. 환경 인터랙트와 멀티플레이어

### 드문 길 열기

환경 인터랙트는 05 책장, 08 나무, 14 책, 17 고철 더미의 선택 지름길에만 넣는다. 한 번 누르면 동작이 끝나고 경로가 열린다. 순서 맞추기, 두 사람이 동시에 누르기, 오래 누르기, 연료 넣기, 문 닫기 토글을 추가하지 않는다.

- 오른쪽 아래 버튼에 대상에 따라 `밀기`, `펼치기`, `치우기`를 표시한다.
- 알 운반 중에는 환경 대상 강조와 환경 작동을 막고 `운반 중` 상태를 읽을 수 있게 한다. 기존 배트 입력과 혼동하지 않는다.
- 누가 열었든 같은 맵의 모두가 사용한다. 여러 명이 동시에 눌러도 한 번만 열린다.
- 열린 길은 같은 활성 맵에서 다시 닫히지 않는다. 재생성·초기화는 플레이어와 운반·드롭 상태가 걸려 있지 않은 안전한 시점에만 기존 맵 생명주기에 맞춰 수행한다.
- 모든 선택 지름길이 닫힌 상태에서도 알까지 갔다가 돌아올 수 있어야 한다.

### 공용 장애물

- 기존 멀티플레이어의 권한 구조와 공유 시간 기준을 사용한다. 각 클라이언트가 따로 무작위 타이머를 시작하지 않는다.
- 경고·작동 위치·충돌·피해가 같은 상태를 따른다. 늦게 들어온 사람도 현재 주기와 열린 지름길 상태를 받는다.
- 누군가 맞거나 알을 줍거나 맵에 들어왔다고 전체 장애물 주기를 갑자기 초기화하지 않는다.
- 움직이는 환경 장애물은 정해진 경로를 따른다. 플레이어를 따라가며 다른 사람의 귀환로로 끌려오는 AI를 새로 넣지 않는다.
- 보스의 기존 추적 규칙은 유지하되 새 후반 활동 범위·홈 위치를 함께 옮긴다. 기존 제한이 필요한 경우 기존의 복귀 체계를 사용한다.
- 떨어진 알과 플레이어의 복귀 위치 판정은 기존 공유 판정 경로와 연결한다. 로컬 효과만 움직이고 서버 판정이 다른 곳에 남지 않게 한다.
- 필수 이동용 연잎·통나무·구름·다리는 고정 지형으로 만든다. 이동하는 배·기차·승강기에 여러 명이 줄 서서 타야 하는 구조는 이번 본길에 넣지 않는다.

## 6. 스테이지별 상세 제작 명세

각 맵은 아래 공간 형태와 구조물을 실제로 다르게 구성한다. 같은 직선 맵의 색과 소품만 바꾸지 않는다. 표의 치수는 P 기준 시작값이며 실제 카메라·이동·인원에 맞춰 조절한다. 각 표에는 주요 구조물을 최소 5개 지정했다. 후반 알자리와 드래곤 흔적은 기존 생성·획득 조건을 유지한 채 장소를 연결한다.

### 01. 몽글 초원

**목표 인상:** 밝은 풀밭 끝에 큰 나무와 둥지가 보인다. 강을 건너 안쪽으로 가고 싶어진다. 가장 쉬운 탐험과 첫 배트 장난을 경험한다.

**전체 형태:** 완만한 S자 길. 25~40%를 가로지르는 얕은 강, 강 건너 넓은 초원, 70%의 거목 앞마당, 92%의 뿌리 둥지로 구성한다. 강의 가운데는 짧은 연잎 길, 오른쪽은 조금 돌아가는 넓은 돌다리다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 목장 입구 | 0~10%, 낮은 나무 울타리와 8P 폭 흙길 | 출구의 눈에 띄는 표식. 문은 항상 열려 있음 |
| 연잎 길 | 25~40%, 폭 5~6P의 고정 연잎 3장, 가장자리가 겹침 | 대표 트롤 지형 1곳. 점프·탑승 대기 없이 건넘 |
| 강변 착지턱 | 연잎 양옆, 얕은 물 바닥과 넓은 흙 경사 | 배트로 빠져도 가까운 물가로 걸어 나옴 |
| 돌다리 | 강 오른쪽, 폭 7P, 낮은 석재 난간 | 처음부터 이용 가능한 편한 우회로 |
| 꽃 둔덕 | 50~58%, 큰 꽃 덩어리와 짧은 순환 산책길 | 나무뿌리에 남은 드래곤 문양을 발견. 알 없음 |
| 거목과 뿌리 둥지 | 65~100%, 굵은 가지와 열린 아치형 뿌리 | 앞마당에 기존 보스, 뒤쪽 뿌리 안에 알 생성 앵커 |

**환경 장애물:** 45% 가장자리의 진흙 웅덩이 하나. 중앙 흙길은 넓고 마르다. 진흙을 밟으면 짧은 감속만 적용하고 환경 피해를 주지 않는다.

**배트 트롤:** 연잎에서 옆 물로 밀면 물방울이 작게 튀고 잠깐 느려진다. 수영 상태로 전환하거나 깊은 물 사망 판정을 넣지 않는다. 두 물가에 모두 가까운 완만한 출구가 있다.

**보스·알·귀환:** 보스는 65~80% 거목 앞의 넓은 잔디에 둔다. 알은 88~100%의 뿌리 안 3개 공간에 기존 생성량을 나눠 배치한다. 뒤쪽 꽃 커튼 틈은 기존 SECRET 관련 알자리 후보다. 알을 얻으면 나무 오른쪽 길을 따라 55%에 합류하고 연잎 또는 돌다리를 골라 돌아온다.

**아트·완료 기준:** 풀은 큰 초록 면, 흙은 따뜻한 갈색, 꽃은 작은 노랑·분홍 포인트로 쓴다. 입구에서 거목이 보여야 하고, 알을 든 두 사람이 연잎에서 서로 비켜갈 수 있어야 한다. 추가 환경 인터랙트 없음.

### 02. 장난감 왕국

**목표 인상:** 커다란 블록 성까지 장난감 방을 걸어가는 느낌. 볼풀로 밀려나는 장난이 직관적으로 보여야 한다.

**전체 형태:** 방 가운데 큰 러그를 기준으로 넓은 U자 동선. 30~45%의 낮은 블록 다리가 볼풀을 가로지르고, 바깥쪽 블록 바닥은 항상 이어져 있다. 후반 성문과 안뜰을 거쳐 장난감 보관실에 도착한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 리본 상자 입구 | 0~10%, 열린 큰 상자와 낮은 경사 | 입구 표식, 뒤를 돌아봐도 알아볼 수 있음 |
| 블록 다리 | 30~45%, 폭 6P, 높이 약 0.5P | 대표 트롤 지형 1곳. 낮은 볼풀 위 지름길 |
| 볼풀 | 다리 양옆, 얕은 사각 영역과 2개 경사 출구 | 밀려난 사람이 공 사이로 걸어서 복귀 |
| 바깥 블록 보도 | 볼풀 외곽, 폭 7P, 모서리가 큰 곡선으로 돌아감 | 편한 우회로. 난간 역할의 큰 블록 배치 |
| 장난감 공 굴림대 | 48~58%, 러그 옆 짧은 경사와 공 받침 | 천천히 움직이는 공의 출발·도착 위치를 보여줌 |
| 블록 성·보관실 | 65~100%, 짧은 탑 2개와 열린 전면 | 성 안뜰에 보스, 뒤 보관 칸에 알자리 |

**환경 장애물:** 공 하나가 러그의 짧은 구간을 천천히 가로지른다. 옆으로 비킬 공간이 충분하고 초반 환경 피해는 없다. 공은 볼풀 낙하 구역과 떨어뜨려 배치해 의도치 않은 두 번째 낙하 함정을 만들지 않는다.

**배트 트롤:** 블록 다리에서 볼풀로 밀면 큰 공 3~5개만 시각적으로 출렁인다. 모든 장식 공을 공유 물리 시뮬레이션에 넣지 않는다. 볼풀 바닥은 평평하며 플레이어와 떨어진 알이 공 밑에 숨지 않는다.

**보스·알·귀환:** 65~82%의 성 안뜰에 보스를 둔다. 88~100% 보관실의 낮은 선반 앞 바닥에 알 앵커를 둔다. 알은 선반 위로 점프해야 닿는 위치에 두지 않는다. 성 옆 열린 아치로 나와 러그 중반에 합류한다. 뒤 리본 커튼의 틈이 후반 숨은 장소다.

**아트·완료 기준:** 빨강·파랑·노랑 블록을 큰 면으로 구분하고 러그는 무광 천으로 표현한다. 알보다 장식 공의 광택이 튀지 않게 한다. 볼풀에서 가장 가까운 출구가 화면에 보여야 한다. 추가 환경 인터랙트 없음.

### 03. 심해 산호숲

**목표 인상:** 큰 산호 아치 사이를 걸어 진주 궁전처럼 생긴 둥지에 도착한다. 수영 조작을 새로 요구하지 않는다.

**전체 형태:** 넓은 해저 보행로가 산호 기둥 사이로 두 번 완만하게 휜다. 30~45%에는 낮은 조개 등 위 지름길과 모래 우회로가 갈라진다. 깊은 해구는 플레이 동선 바깥의 배경으로 표현한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 산호 입구 아치 | 0~12%, 굵은 가지 3개로 만든 열린 문 | 진행 방향을 안내하는 큰 실루엣 |
| 고정 조개 보행판 | 30~45%, 폭 6P, 납작한 큰 조개 등 | 대표 트롤 지형 1곳. 닫히거나 회전하지 않음 |
| 해초 착지밭 | 조개 양옆, 낮은 초록·청록 잎 덩어리 | 밀려나면 제한된 감속. 모래길로 바로 복귀 |
| 모래 우회로 | 조개 바깥, 폭 7P, 큰 돌 경계 | 배트 지형을 거치지 않는 편한 길 |
| 거품 분출구 | 48~58%, 가장자리의 둥근 구멍 2개 | 물줄기 작동 전 거품으로 알려줌 |
| 진주 산호 전당 | 65~100%, 큰 산호 부채와 낮은 조개 받침 | 전면 보스 공간, 후면 알자리와 숨은 진주 굴 |

**환경 장애물:** 거품이 올라온 뒤 물줄기가 나온다. 1~5의 쉬운 구간이므로 중앙 보행로는 안전하게 남기고, 가장자리 물줄기에 닿아도 작은 밀림 정도만 준다. 효과가 큰 해초와 알을 가리지 않게 한다.

**배트 트롤:** 조개 위에서 옆 해초로 밀어낸다. 해초는 발밑만 감싸고 얼굴·운반 알·상대 위치를 완전히 가리지 않는다. 양쪽에 모래 복귀 구간이 이어져 있다.

**보스·알·귀환:** 보스는 65~82%의 평평한 전당 앞에 둔다. 알은 88~100%의 낮은 조개 받침 주변 바닥에 분산한다. 뒤 산호 부채 사이에 후반 숨은 굴을 둔다. 귀환은 전당 좌우 모래길 중 하나로 55%에 합류한다.

**아트·완료 기준:** 산호는 분홍·보라의 큰 가지, 바닥은 청록과 따뜻한 모래색으로 구분한다. 반투명 재질은 일부 조개·물 효과에만 쓴다. 실제 깊은 구멍으로 빠지는 길이나 이동 거북 탑승 병목은 만들지 않는다. 추가 환경 인터랙트 없음.

### 04. 화산 대장간

**목표 인상:** 위험해 보이는 용암을 배경으로, 넓은 작업 발판을 따라 커다란 화로까지 간다. 실제 플레이 난도는 여전히 쉽다.

**전체 형태:** 대장간 작업장을 돌아 화로 뒤편까지 가는 넓은 ㄷ자 동선. 30~45%에 낮은 철제 작업 발판을 둔다. 용암은 외곽 차단 구조 너머로 보이고, 배트로 밀릴 수 있는 안쪽 낙하 범위는 숯 바닥으로 받친다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 작업장 입구 | 0~12%, 열린 철골 문과 넓은 바닥 | 큰 모루 장식으로 출구를 알아보게 함 |
| 철제 작업 발판 | 30~45%, 폭 6P, 낮은 철판과 굵은 지지대 | 대표 트롤 지형 1곳 |
| 숯더미 착지장 | 발판 양옆, 검은 무광 숯과 넓은 경사 | 밀려나면 가루가 튀고 가까운 길로 복귀 |
| 난간 있는 작업 통로 | 발판 바깥, 폭 7P | 처음부터 연결된 우회로 |
| 외곽 용암 수로 | 주동선 밖, 밝은 균열과 두꺼운 석재 경계 | 화산 인상을 만드는 배경. 초반 필수 피해 구간 아님 |
| 거대한 화로와 뒤 보관대 | 65~100%, 굵은 굴뚝·큰 철판·넓은 후면 공간 | 전면 보스, 후면 알자리 |

**환경 장애물:** 길 밖 작은 분출구가 먼저 빛나고 불꽃을 낸다. 본길 중앙은 안전하며 초반 학습용 연출로 사용한다. 외곽 불꽃과 실제 통행 가능한 숯 바닥의 색·움직임을 명확히 구분한다.

**배트 트롤:** 작업 발판에서 숯더미로 밀어내면 작은 검은 가루 효과만 잠깐 나온다. 화면 전체를 검게 가리거나 알을 보이지 않게 하지 않는다. 실제 넉백이 외곽 용암까지 닿지 않게 넓은 착지장과 보이는 작업장 벽을 구성한다.

**보스·알·귀환:** 65~82%의 화로 앞 광장에 기존 보스, 88~100%의 화로 뒤 낮은 보관대 주변에 알을 둔다. 귀환은 화로 양옆의 폭 6P 이상 작업 통로로 빠져나온다. 뒤편 흑요석 틈은 후반 숨은 알자리 후보이며 들어가고 나올 때 버튼이 필요 없다.

**아트·완료 기준:** 큰 무광 암석·거친 철판과 좁은 주황빛을 대비한다. 전신 발광 바닥을 만들지 않는다. 초반에 용암 낙사나 길을 여는 필수 철판 버튼을 추가하지 않는다. 추가 환경 인터랙트 없음.

### 05. 유령 학교

**목표 인상:** 익숙한 학교 안을 구경하며 가장 안쪽 교장실을 찾는다. 느린 유령과 매트 장난으로 초반 구간을 마무리한다.

**전체 형태:** 입구 복도에서 왼쪽 체육관 또는 오른쪽 교실 복도로 갈라졌다 다시 합류한다. 체육관은 짧은 길, 교실 쪽은 넓고 편한 길이다. 끝의 큰 시계 아래 보스 공간을 거쳐 교장실에 도착한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 학교 현관 | 0~12%, 큰 신발장과 열린 출입문 | 돌아올 입구를 기억하게 하는 표식 |
| 체육관 낮은 무대 | 28~42%, 폭 6P, 높이 약 0.5P | 대표 트롤 지형 1곳. 옆으로 밀면 매트에 착지 |
| 매트와 측면 경사 | 무대 양옆, 큰 접힌 매트 2~3덩어리 | 알을 든 채 걸어 올라오는 복귀 공간 |
| 교실 복도 | 체육관 바깥, 폭 7P, 큰 열린 교실문 | 처음부터 이용 가능한 편한 우회로 |
| 이동 책장 | 45~55%, 두 교실 사이의 짧은 연결로 앞 | 선택 인터랙트 `밀기`. 열면 모두 쓰는 짧은 샛길 |
| 시계 홀과 교장실 | 65~100%, 큰 벽시계와 전면이 열린 방 | 홀에 보스, 뒤쪽 교장실 바닥에 알자리 |

**환경 장애물:** 유령 하나가 50~60% 복도 한쪽을 천천히 왕복한다. 옆 교실에 넓은 빈 공간이 있고, 닿아도 새 환경 피해 없이 잠깐 느려지는 정도다. 유령이 좁은 출입문을 계속 점유하지 않는다.

**배트 트롤:** 무대에서 매트로 밀면 푹신한 눌림과 작은 먼지 효과를 보인다. 실제 무한 바운스·넘어짐 잠금은 넣지 않는다. 양쪽 경사로가 가까워 몇 걸음이면 복귀한다.

**보스·알·귀환:** 보스는 65~82% 시계 홀, 알은 88~100% 교장실의 책상 앞·옆 바닥에 분산한다. 후반 책 더미 옆 틈은 숨은 서재로 이어진다. 귀환은 교장실 측면 문을 통해 55% 교실 복도로 합류한다. 문은 상시 개방이다.

**인터랙트:** 책장은 한 번 밀면 열린 위치에 유지한다. 닫힌 상태에서도 교실 복도로 왕복 가능하다. 서재 입구나 귀환 문에 추가 버튼을 붙이지 않는다.

**아트·완료 기준:** 칠판 초록, 오래된 나무 갈색, 분필 흰색을 큰 면으로 사용한다. 밤에도 문턱·귀환 길·유령 위치가 보인다. 05까지는 환경 요소 때문에 알이 자동 소멸하거나 즉사하지 않는다.

### 06. 네온 사이버시티

**목표 인상:** 큰 간판이 보이는 도시 안쪽까지 횡단보도와 보행로를 따라간다. 처음으로 앞을 보고 기다려야 하는 환경 장애물을 만난다.

**전체 형태:** 넓은 보행 광장, 횡단 도로, 낮은 고가 지름길, 후반 네온 타워 순서로 깊어진다. 복잡한 다층 미로 대신 위층과 아래층이 동시에 보이는 낮은 단차만 사용한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 역 출구 광장 | 0~12%, 큰 출구 간판과 밝은 보도 | 입구와 귀환 방향의 표식 |
| 첫 횡단보도 | 18~28%, 폭 8P 이상, 양쪽 대기 공간 | 로봇이 지난 다음 건너는 학습 구간 |
| 낮은 고가 보행로 | 35~48%, 폭 6P, 아래 인도가 보임 | 대표 트롤 지형 1곳 |
| 아래 인도·복귀 계단 | 고가 양옆, 넓은 착지 바닥과 완만한 경사 | 차도에 떨어지지 않고 복귀 |
| 상점가 우회로 | 고가 외곽, 폭 7P, 큰 쇼윈도 2~3개 | 편한 길과 중간 탐험 공간 |
| 네온 타워 앞마당·뒤 배송장 | 65~100%, 큰 수직 간판과 열린 후면 | 보스와 알자리의 시각적 목적지 |

**환경 장애물:** 배달 로봇이 18~28% 도로를 일정한 방향으로 지나간다. 로봇은 같은 길을 왕복하거나 안전하게 순환하며 플레이어를 추적하지 않는다. 대기 공간에서 전체 이동을 볼 수 있다. 처음에는 한 종류, 한 구간만 필수로 통과한다.

**배트 트롤:** 고가에서 밀면 아래 인도로 떨어진다. 착지점은 로봇 차도와 분리한다. 복귀 계단이 양끝에 있고, 고가 대신 상점가로 걸으면 낙하 위험을 피할 수 있다.

**보스·알·귀환:** 보스는 65~82% 타워 앞 광장, 알은 88~100% 뒤 배송장 바닥의 큰 상자 사이에 둔다. 상자는 알을 가리거나 좁은 틈을 만들지 않는다. 뒤 네온 벽 틈에는 후반 숨은 정비실을 둔다. 귀환은 타워 측면 골목으로 55% 상점가에 합류한다.

**아트·완료 기준:** 어두운 청회색 건물, 큰 청록·분홍 간판, 밝은 보도를 대비한다. 글자 많은 간판 대신 큰 기호를 쓴다. 06의 첫 횡단은 가장 느린 운반 상태에서도 대기 후 무리 없이 건널 수 있어야 한다. 추가 환경 인터랙트 없음.

### 07. 황금 사막왕국

**목표 인상:** 큰 피라미드를 향해 모래언덕과 유적 기둥 사이를 탐험한다. 굴러오는 돌을 보고 옆으로 비키는 구간이다.

**전체 형태:** 입구 오아시스에서 낮은 언덕 능선을 따라 올라가 피라미드 앞 넓은 모래 광장에 도착한다. 30~45% 능선 지름길과 외곽 돌바닥 길이 갈라진다. 후반까지 피라미드의 큰 윤곽을 볼 수 있게 한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 오아시스 입구 | 0~12%, 낮은 야자수와 넓은 마른 모래길 | 출구 표식, 물은 길을 막지 않음 |
| 모래 능선 | 30~45%, 폭 6P, 양옆으로 완만한 경사 | 대표 트롤 지형 1곳 |
| 아래 모래 그릇 | 능선 옆, 넓고 얕은 오목한 땅 | 밀리면 아래로 미끄러지고 옆길로 복귀 |
| 석재 우회로 | 능선 외곽, 폭 7P, 낮은 벽돌 경계 | 미끄러지지 않는 편한 길 |
| 돌 굴림 경사 | 48~58%, 본길 옆 높은 바위와 받침 공간 | 돌의 이동 방향을 멀리서 읽게 함 |
| 피라미드 전정·후실 | 65~100%, 넓은 문과 전면이 열린 실내 | 전정에 보스, 가장 안쪽 후실에 알 |

**환경 장애물:** 바위 하나가 정해진 비탈을 따라 길을 가로지른다. 내려오기 전 모래가 조금 떨어지고 바위가 흔들린다. 바위는 통과 후 플레이어를 밀어 올리거나 튕기며 다시 공격하지 않고 받침 구역으로 빠진다.

**배트 트롤:** 능선에서 맞으면 낮은 모래 분지로 미끄러진다. 경사 아래에 깊은 구멍이나 매몰 타이머는 없다. 양쪽 경사 복귀길과 외곽 석재 우회로를 눈에 띄게 만든다.

**보스·알·귀환:** 65~82% 피라미드 전정에 보스, 88~100% 후실의 낮은 석재 받침 주위에 알을 둔다. 후실 옆 벽의 큰 틈은 숨은 작은 방으로 연결한다. 귀환은 피라미드 측면 통로를 통해 58% 유적 기둥 사이로 합류한다. 열쇠·태양 방향 퍼즐은 없다.

**아트·완료 기준:** 모래는 황토·밝은 베이지, 피라미드는 큰 사암 면, 금색은 문양에만 집중한다. 낮·밤 어느 때나 돌 그림자와 모래 경사 방향이 읽혀야 한다. 추가 환경 인터랙트 없음.

### 08. 태초의 공룡섬

**목표 인상:** 큰 발자국과 거대한 알껍질을 따라 원시 숲 안쪽으로 간다. 공룡 발 그림자를 보고 피한다.

**전체 형태:** 강을 가로지르는 중앙 통나무와 동쪽 돌다리에서 갈라진 뒤, 양치식물 평지와 뿌리 둥지로 이어진다. 숲은 벽처럼 빽빽하게 채우지 말고 큰 잎과 줄기를 덩어리로 배치한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 양치식물 입구 | 0~12%, 큰 잎 3~4덩어리와 화석 표식 | 출구를 기억하는 랜드마크 |
| 고정 통나무 다리 | 30~45%, 폭 6P, 굵은 목재 단면 | 대표 트롤 지형 1곳 |
| 얕은 강·강변 길 | 통나무 양옆, 연속된 낮은 바닥과 흙 경사 | 밀려나면 강변을 따라 복귀 |
| 넓은 돌다리 | 중앙 통나무 바깥, 폭 7P | 처음부터 열린 편한 우회로 |

**환경 장애물:** 짧은 얼음의 제한된 미끄러움과 일정 경로로 구르는 눈덩이를 서로 분리한다. 눈길에 닿으면 정상적으로 멈출 수 있다. 미끄러움 때문에 운반자의 방향 입력이 장시간 무시되거나 최대 속도가 무한히 증가하지 않게 한다.

**배트 트롤:** 중앙 얼음에서 맞으면 옆 눈더미 쪽으로 길게 미끄러진다. 눈더미가 명확한 종착점이며 얼음 밖으로 나가면 추가 관성은 빠르게 줄어든다. 멈춘 뒤 양쪽 눈길 중 가까운 곳으로 복귀한다. 눈덩이 공격과 착지장을 겹치지 않는다.

**보스·알·귀환:** 보스는 65~82% 얼음궁 앞, 알은 88~100% 뒤 얼음굴의 불투명한 눈 받침에 둔다. 굴 옆 큰 얼음 틈은 후반 숨은 장소다. 귀환은 얼음궁 측면 눈길로 58%에 합류한다. 알 무게 때문에 바닥이 깨지는 규칙은 넣지 않는다.

**아트·완료 기준:** 두꺼운 얼음 청록, 얇은 끝 청백색, 눈의 따뜻한 흰색을 구분한다. 알과 얼굴을 가리는 전면 굴절을 사용하지 않는다. 얼음은 멈추기 어려운 구간, 눈은 멈출 수 있는 구간이라는 관계가 일관돼야 한다. 추가 환경 인터랙트 없음.

### 14. 뒤죽박죽 꿈나라

**목표 인상:** 거대한 침대·책·찻잔 사이를 작은 캐릭터가 걸어간다. 물건 크기는 이상하지만 걷는 규칙은 평범하다.

**전체 형태:** 큰 책상 가장자리에서 침대를 지나 뒤쪽 베개 성으로 이어진다. 책상과 침대는 고정된 넓은 경사로로 연결한다. 카메라 회전, 중력 뒤집기, 좌우 입력 반전은 없다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 찻잔 입구 | 0~12%, 큰 찻잔과 바닥에 놓인 스푼 표식 | 출구와 규모감의 기준 |
| 침대 위 지름길 | 30~45%, 폭 6P, 큰 봉제 면의 매트리스 | 대표 트롤 지형 1곳 |
| 옆 베개 언덕 | 침대 옆, 낮고 넓은 푹신한 착지 바닥 | 밀려나면 작은 탄성 표현 후 걸어 복귀 |
| 러그 우회로 | 침대 바깥, 폭 7P, 고정 경사로 연결 | 편한 길 |
| 펼칠 수 있는 큰 책 | 48~56%, 낮은 책상 사이의 선택 연결로 | 인터랙트 `펼치기`. 페이지가 고정 지름길이 됨 |
| 베개 성 전정·뒤 수면 정원 | 65~100%, 큰 천 덩어리와 별 모양 포인트 | 보스와 후반 알자리 |

**환경 장애물:** 52~62%에서 큰 베개 하나가 느리게 올라갔다 내려온다. 그림자로 내려오는 자리를 보여주며 올라간 동안 걸어서 통과한다. 경고·휴식이 충분하고 양쪽에 넓은 대기 공간이 있다. 침대 트롤 지형과 분리한다.

**배트 트롤:** 침대에서 밀리면 옆 베개 쪽으로 낮게 튕긴다. 탄성을 구현한다면 짧은 한 번의 반응으로 끝내고 연속 바운스나 제어 상실을 반복하지 않는다. 베개 사이에는 충돌이 끊기지 않는 넓은 복귀 길이 있다.

**보스·알·귀환:** 보스는 65~82% 베개 성 앞, 알은 88~100% 뒤 수면 정원의 낮은 천 받침 위에 둔다. 큰 찻잔 뒤 작은 과자집 입구가 후반 숨은 장소다. 귀환은 성 측면의 러그 길을 따라 58%에 합류한다.

**인터랙트:** 큰 책은 한 번 펼치면 유지된다. 페이지는 두껍고 양옆이 말려 난간 역할을 하며 아래에도 연속 바닥이 있어 별도의 낙하 트롤 포인트가 되지 않는다. 책이 닫혀 있어도 러그 길로 왕복 가능하다.

**아트·완료 기준:** 넓은 크림색 천, 보라·민트색 소품, 제한된 별사탕 포인트를 쓴다. 모든 물건을 움직이게 하지 않는다. 원근과 크기는 장난스럽게, 실제 보행 면과 출구 방향은 안정적으로 유지한다.

### 15. 방사능 폐허

**목표 인상:** 낡은 거리 사이에 살아 있는 작은 온실이 보인다. 마른 길과 진흙, 잠깐 새는 가스를 구분하며 안쪽으로 이동한다.

**전체 형태:** 무너진 건물 사이를 크게 휘어 지나가는 거리. 30~45% 중앙 마른 길은 진흙밭을 짧게 가로지르고, 외곽 콘크리트 보도는 넓게 돌아간다. 후반 깨진 돔과 재생 온실이 목적지다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 무너진 버스 정류장 | 0~12%, 큰 지붕과 단순한 표지 | 출구의 고유한 실루엣 |
| 진흙 사이 마른 길 | 30~45%, 폭 6P, 밝은 갈색 단단한 바닥 | 대표 트롤 지형 1곳 |
| 진흙밭 | 마른 길 양옆, 낮고 넓은 어두운 흙 | 밀리면 감속, 가까운 마른 가장자리로 복귀 |
| 콘크리트 우회 보도 | 진흙 바깥, 폭 7P, 낮은 경계석 | 편한 우회로 |
| 깨진 배관 거리 | 48~62%, 큰 파이프와 넓은 건물 입구 | 가스 분출·대기 공간 |
| 깨진 돔·재생 온실 | 65~100%, 큰 유리판과 굵은 식물 줄기 | 보스 앞마당과 후반 알자리 |

**환경 장애물:** 배관이 흔들리고 초록 연기가 조금 나온 뒤 짧게 가스가 퍼진다. 위험 범위를 바닥 형태와 함께 표시한다. 두 분출구를 쓸 경우 떨어뜨려 배치한다. 진흙 감속 구역을 가스 피격 영역으로 겹쳐 출구 없는 피해 구간을 만들지 않는다.

**배트 트롤:** 마른 지름길에서 진흙으로 밀어낸다. 진흙은 방사능 피해 구역이 아니라 제한된 감속 구역이다. 길을 찾을 수 없을 정도로 알과 발을 숨기지 않는다. 감속 상태라도 가장 가까운 마른 땅으로 계속 걸어갈 수 있다.

**보스·알·귀환:** 보스는 65~82% 깨진 돔 앞, 알은 88~100% 온실 안의 낮은 화단 사이에 둔다. 후반 벽 틈의 작은 꽃밭이 숨은 장소다. 귀환은 온실 옆 열린 정비 길로 58%에 합류한다. 방독면·필터 수명 같은 새 관리 시스템은 넣지 않는다.

**아트·완료 기준:** 녹슨 주황·콘크리트 회색·새싹 초록을 큰 면으로 배치한다. 오염 텍스처를 작은 얼룩으로 빽빽하게 채우지 않는다. 장식 안개와 실제 가스 위험 구역이 구별돼야 한다. 추가 환경 인터랙트 없음.

### 16. 곤충 소인국

**목표 인상:** 풀잎과 버섯이 건물처럼 큰 세계. 뿌리를 타고 안쪽 꽃둥지까지 올라간다.

**전체 형태:** 나무뿌리 주변을 감는 완만한 오르막 동선. 중반 버섯 위 지름길과 아래 흙길이 갈라진다. 후반까지 점프 없이 올라갈 수 있도록 모든 높이 변화에 굵은 뿌리 경사를 연결한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 도토리 입구 | 0~12%, 반쯤 열린 큰 도토리와 흙길 | 출구의 고유한 표식 |
| 넓은 버섯 발판 | 30~45%, 폭 6P, 납작한 갓과 굵은 줄기 | 대표 트롤 지형 1곳 |
| 기울어진 큰 잎 | 버섯 옆, 넓고 연속된 경사면 | 밀리면 잎을 따라 아래 뿌리길에 착지 |
| 흙길·뿌리 경사로 | 버섯 바깥, 폭 7P, 끊기지 않는 바닥 | 편한 우회와 착지 복귀 |
| 개미 횡단로·이슬 잎 | 48~62%, 두 구간 사이 넓은 흙 쉼터 | 개미를 기다리고 물방울 그림자를 피하는 공간 |
| 꽃뿌리 전정·안쪽 꽃둥지 | 65~100%, 큰 꽃잎과 굵은 줄기 아치 | 앞 보스, 뒤 알자리 |

**환경 장애물:** 개미 무리가 한 줄로 지나가는 곳과 큰 물방울이 떨어지는 곳을 분리한다. 개미는 정해진 환경 경로만 따라가며 보스나 신규 수집 종으로 등록하지 않는다. 물방울은 커지는 그림자와 잎의 흔들림으로 알린다. 두 장애물 사이에 완전히 안전한 대기 바닥을 둔다.

**배트 트롤:** 버섯에서 밀리면 넓은 잎의 경사를 따라 아래 뿌리길로 미끄러진다. 잎 끝은 허공이 아니라 넓은 흙 바닥과 연결된다. 떨어진 알도 접근 가능한 바닥에 도달한다. 복귀는 뿌리 경사로를 걸어 올라오는 방식이다.

**보스·알·귀환:** 보스는 65~82% 꽃뿌리 앞마당, 알은 88~100% 꽃잎 안쪽의 낮은 꽃가루 받침 주변에 둔다. 뒤 버섯 아래 열린 도토리 저장실이 숨은 장소다. 귀환은 큰 줄기 옆 경사로로 58% 흙 쉼터에 합류한다.

**아트·완료 기준:** 굵은 잎맥 몇 줄, 큰 점무늬 버섯, 따뜻한 흙을 사용한다. 작은 풀 수백 개로 길을 가리지 않는다. 식물 사이 빈 공간이 실제로 통과 가능한지 충돌을 정리한다. 추가 환경 인터랙트 없음.

### 17. 고철 로봇행성

**목표 인상:** 고철을 운반하는 공장 안쪽 거대 로봇 작업장으로 간다. 배트로 상대를 반대 방향 벨트에 밀어 넣는 장난이 핵심이다.

**전체 형태:** 입구 작업장, 나란한 컨베이어, 압착기 구간, 후반 로봇 조립장 순서다. 모든 공장 설비가 움직이는 것처럼 보이더라도 실제 피해 장치는 명확히 지정한 압착기뿐이다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 고철 입구 아치 | 0~12%, 큰 교체 부품 3~4개와 넓은 바닥 | 출구 표식 |
| 쌍방향 컨베이어 구간 | 30~45%, 각 벨트 폭 5P 이상, 가운데 낮은 경계 | 두 벨트를 합쳐 대표 트롤 지형 1곳 |
| 벨트 옆 고정 발판 | 벨트 양끝과 중간 옆, 넓은 불투명 철판 | 잘못 탄 방향에서 걸어 내리는 탈출 공간 |
| 공장 외곽 보행로 | 벨트 바깥, 폭 7P, 난간과 큰 화살표 | 편한 우회로 |
| 고철 더미·집게 | 46~54%, 선택 정비 샛길 입구 | 인터랙트 `치우기`. 집게가 고철을 들어 샛길 개방 |
| 압착기 홀·거대 로봇 정비장 | 55~100%, 분리된 압착 구간 뒤 넓은 작업장 | 환경 장애물, 보스, 후반 알자리 |

**환경 장애물:** 55~64%의 압착기 2~3개가 떨어진 위치에서 순서대로 움직인다. 각각 경고등뿐 아니라 실제 판이 먼저 떨리게 한다. 판 사이에 완전히 안전한 발판을 둔다. 같은 사람에게 한 판의 하강으로 여러 번 피해를 주지 않는다.

**배트 트롤:** 한쪽 벨트의 플레이어를 옆 반대 방향 벨트로 밀면 반대쪽으로 잠깐 실려 간다. 벨트는 운송차가 아니라 넓은 고정 보행면이며 언제든 옆 발판으로 걸어 나올 수 있다. 벨트 끝에는 벽이나 받침이 있고 압착기·구덩이로 바로 넣지 않는다. 돌아올 때는 반대 방향 벨트를 선택할 수 있다.

**보스·알·귀환:** 보스는 68~84% 거대 로봇 앞 작업장, 알은 88~100% 로봇의 열린 정비실 바닥에 둔다. 보스 자체를 그 거대 배경 로봇으로 교체하지 않는다. 후반 옆 창고 문틈이 숨은 장소다. 귀환은 측면 고정 보행로로 60%의 안전 발판에 합류한다.

**인터랙트:** 집게는 고철 제거 시 한 번 움직인 뒤 물체를 안전한 배경 위치에 고정한다. 플레이어를 붙잡거나 들어 올리는 새 기능은 없다. 고철이 남아 있어도 외곽 보행로는 열려 있다. 압착기를 끄는 필수 버튼을 추가하지 않는다.

**아트·완료 기준:** 큰 금속 판의 교체 흔적, 굵은 볼트 몇 개, 노랑·검정 방향 표식을 사용한다. 실제 이동 방향과 화살표 방향이 일치해야 한다. 벨트 위 배트 피격·알 드롭·재진입이 멀티에서 같은 결과를 보여야 한다.

| 분화구 경사·바깥 데크 | 테두리 바깥, 폭 7P, 낮은 난간 | 편한 우회와 걸어서 복귀 |
| 운석 관측 바닥 | 48~64%, 넓은 판과 여러 안전 섬 | 운석 착지 표시를 보고 피하는 구간 |
| 천문대 돔·뒤 관측 정원 | 68~100%, 큰 망원경과 별고리 장식 | 앞 보스, 뒤 알자리 |

**환경 장애물:** 작은 운석이 표시된 원에 떨어진다. 초반 번개와 같은 ‘표시 밖으로 나가기’ 규칙을 사용한다. 후반답게 떨어진 두 지점에 차례로 표시할 수 있지만 안전 통로 전체를 덮지 않는다. 운석 파편은 장식이며 별도 다단 피해를 자동 추가하지 않는다.

**배트 트롤:** 분화구 테두리에서 안쪽으로 밀면 낮은 바닥으로 굴러간다. 바깥쪽은 낮은 보이는 난간·넓은 데크로 보호한다. 분화구에는 눈에 잘 보이는 완만한 경사 출구 두 개를 둔다. 우주 밖으로 영원히 날아가게 만들지 않는다.

**보스·알·귀환:** 보스는 68~84% 천문대 앞, 알은 88~100% 뒤 관측 정원의 낮은 받침 주변에 둔다. 큰 망원경 지지대 뒤 열린 작은 관측실이 숨은 장소다. 귀환은 돔 측면으로 돌아 60% 관측 바닥의 안전 가장자리에 합류한다.

**아트·완료 기준:** 짙은 남보라 배경, 밝은 달 표면, 제한된 금색·청록 별빛을 사용한다. 장식 별점과 실제 운석 표시를 구별한다. 거대한 천체가 카메라와 플레이어 사이를 지나가 시야를 막지 않게 한다. 추가 환경 인터랙트 없음.

### 19. 공허의 틈

**목표 인상:** 검은 공간에 남은 단단한 돌길을 따라 거대한 문까지 간다. 위험은 기묘하게 보이되 이동 규칙은 단순하다.

**전체 형태:** 위쪽 지름길과 아래쪽 복귀 길이 한 화면 안에 읽히는 두 층 구조. 30~45% 위쪽 돌다리가 대표 지름길이고 외곽은 넓은 연결 회랑이다. 후반 큰 문과 그 뒤 고요한 공간까지 이어진다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 갈라진 기둥 입구 | 0~12%, 큰 돌기둥과 밝은 바닥 가장자리 | 출구 방향의 표식 |
| 위층 돌다리 | 30~45%, 폭 6P, 아래 길이 바로 보임 | 대표 트롤 지형 1곳 |
| 아래 돌길 | 다리 아래, 폭 넓은 연속 바닥과 외곽 돌 난간 | 밀려난 사람의 착지 공간 |
| 외곽 회랑·복귀 경사 | 돌다리 바깥, 폭 7P, 긴 완만한 오르막 | 편한 우회로와 낙하 복귀 |
| 검은 벽 통과 구간 | 48~64%, 넓은 바닥과 쉬는 섬 | 큰 빈칸이 있는 움직이는 벽을 통과 |
| 경계의 문·뒤 정적 공간 | 68~100%, 두께 있는 큰 문과 밝은 돌 받침 | 앞 보스, 뒤 알자리 |

**환경 장애물:** 검은 벽이 천천히 지나가되 바닥부터 위까지 이어진 넓은 빈칸을 남긴다. 외계 연구소에서 배운 규칙을 재사용한다. 떨어진 두 구간에서 빈칸의 위치를 다르게 할 수 있지만 그 사이에는 완전히 안전한 바닥을 둔다. 점프해서 넘거나 외워야 하는 투명 길은 없다.

**배트 트롤:** 위층 돌다리에서 밀리면 아래 돌길에 착지한다. 이 맵은 복귀 경사 길이 조금 길어 우회 비용이 크지만 진행 상태를 초기화하지 않는다. 아래층 경계도 보호해 한 번 더 맞았다고 끝없는 공허로 추락하지 않게 한다.

**보스·알·귀환:** 보스는 68~84% 큰 문 앞, 알은 88~100% 문 뒤의 밝은 바닥 받침에 둔다. 문 옆 넓은 균열 입구는 후반 숨은 작은 공간으로 연결한다. 귀환은 문 측면 외곽 회랑을 따라 60% 안전 섬에 합류한다.

**아트·완료 기준:** 검정 배경과 보라·청백색 경계를 대비하되 바닥 자체는 충분히 불투명하고 두께가 있어야 한다. 걷는 바닥이 사라지는 효과는 넣지 않는다. 실제 충돌과 보이는 돌의 위치가 일치해야 한다. 추가 환경 인터랙트 없음.

### 20. 창조주의 정원

**목표 인상:** 강·거목·꽃 정원이 연결된 마지막 탐험 공간. 지금까지 익힌 이동과 피하기로 가장 깊은 둥지까지 도달한다.

**전체 형태:** 입구에서 중앙 거목이 크게 보이고, 강변 산책길을 따라 뿌리 지름길 또는 바깥 정원길을 선택한다. 중반 이후 씨앗 굴림 구간과 물줄기 구간을 순서대로 지나 거목 앞마당과 뒤 둥지에 도착한다.

| 구조물 | 배치·형태 | 기능 |
| --- | --- | --- |
| 씨앗 문 입구 | 0~12%, 벌어진 큰 씨앗 껍질과 넓은 잔디 | 출구 표식과 중앙 거목 조망 |
| 거목 뿌리 지름길 | 30~45%, 폭 6P, 굵은 파츠가 완만하게 휨 | 대표 트롤 지형 1곳 |
| 아래 연못·고정 연잎 길 | 뿌리 아래, 넓은 연잎이 겹쳐 연속된 바닥 | 밀려나면 착지하고 강변으로 복귀 |
| 바깥 정원 산책로 | 뿌리 외곽, 폭 7P, 낮은 꽃 울타리 | 편한 우회로 |
| 씨앗 언덕·물줄기 정원 | 48~64%, 두 구간 사이 넓은 잔디 쉼터 | 익숙한 굴러오는 물체와 분출구를 차례로 통과 |
| 거목 전정·안쪽 첫 둥지 | 68~100%, 큰 줄기와 열린 뿌리 아치 | 마지막 보스 공간과 후반 알자리 |

**환경 장애물:** 큰 씨앗이 정해진 길을 굴러온다. 이를 통과하면 안전한 잔디 쉼터가 있고, 다음에는 물줄기가 솟는다. 두 위험을 같은 위치에 겹치지 않는다. 마지막 맵이라는 이유로 새로운 입력·반응 속도 시험·동시 네 종류 공격을 추가하지 않는다.

**배트 트롤:** 뿌리 위에서 밀리면 아래의 고정 연잎에 착지한다. 초원의 연잎과 같은 시각 언어를 쓰되 복귀 강변이 더 길다. 모든 연잎 사이가 연결돼 있고 기다려 타는 배나 점프 구간은 없다.

**보스·알·귀환:** 보스는 68~84% 거목 전정, 알은 90~100% 안쪽 첫 둥지의 큰 뿌리 받침 주변에 둔다. 뿌리 뒤 작은 계절 정원이 후반 숨은 장소다. 귀환은 거목 측면 잔디길을 따라 62% 쉼터에 합류하고, 물줄기와 씨앗 구간을 거슬러 본 뒤 중앙 뿌리 또는 외곽 길을 선택한다.

**아트·완료 기준:** 큰 초록과 따뜻한 흙, 크림색 꽃, 제한된 금빛 씨앗을 사용한다. 온 맵을 금색·무지개·발광으로 덮지 않는다. 첫 맵의 편안한 소재가 더 큰 구조로 확장된 느낌을 주고, 알자리의 얼굴과 알 색은 끝까지 읽혀야 한다. 추가 환경 인터랙트 없음.

## 7. 보스·알 생성 위치를 옮길 때의 적용 규칙

1. 실제 스테이지 ID와 현재 보스·알 스폰 데이터를 대응시킨다. 문서의 순서 번호를 런타임 ID로 단정하지 않는다.
2. 보스 인스턴스를 복제해 후반에 하나 더 만들지 않는다. 기존 인스턴스의 생성점·홈 위치·활동 범위·기존 복귀 경로를 일관되게 옮긴다. 이미 보스가 여러 종류인 스테이지라면 모두 기존 역할을 유지한 채 후반 영역 안에서 배치한다.
3. 보스 공격이 기존 입구 좌표를 향하거나 새 벽 뒤에서 생성되지 않게 연결된 좌표·참조를 확인한다. 보스의 수치·종류·모델은 유지한다.
4. 알 생성기는 새 위치 앵커를 사용하게 하고 중반의 옛 자연 생성 지점을 정리한다. 생성기를 추가 복제해 총 생성량이 늘지 않게 한다.
5. 생성된 알의 획득 ID와 소유·드롭 상태를 유지한다. 플레이어가 중반에서 떨어뜨린 알은 자연 생성 알과 다르므로 ‘후반 배치 규칙’을 이유로 맵 뒤로 강제 이동하지 않는다.
6. 새 알 앵커는 85~100% 후반 보행 공간 안에 있어야 한다. 장식 선반·벽·천장·보스 몸 안이나 필수 인터랙트 뒤에 끼우지 않는다.
7. 기존 SECRET 알 조건·확률·연결 드래곤은 유지한다. 모든 숨은 장소에 SECRET을 확정 생성하거나 새 SECRET 수를 늘리지 않는다.
8. 이미 획득한 알·운반 중인 알·플레이어 저장 인스턴스를 새 맵 배치로 초기화하지 않는다. 활성 세션의 지형 변경은 기존 맵 교체 생명주기에 맞추고 플레이어 아래에서 바닥을 삭제하지 않는다.
9. 귀환 측면 길은 본길과 다시 만나는 순환로다. 입구에서 알자리까지를 직선으로 건너뛰는 새 통로가 되지 않게 실제 최단 경로도 확인한다. 반대 방향으로 걸어도 후반까지 탐험해야 한다.
10. 기존 알 반납·기지·출구 시스템과 연결한다. 이번 문서에 없는 자동 반납, 즉시 수익 지급, 휴대 순간 저장 완료 같은 규칙을 만들지 않는다.

| 후반 난도 | 06부터 관찰·대기·경로 선택이 점점 중요해짐. 새 입력이나 강제 점프 없음 |
| 배트 지형 | 각 맵 대표 1곳, 합계 20곳. 맞은 뒤 접근 가능한 착지와 보행 복귀가 있음 |
| 환경 인터랙트 | 선택 길 열기는 05·08·14·17에만 존재. 전부 닫혀 있어도 왕복 가능 |
| 운반 귀환 | 인터랙트를 금지한 채 알자리부터 입구까지 통과 가능 |
| 후반 배치 | 기존 보스가 60~85%, 자연 생성 알 앵커가 85~100% 후반에 있음 |
| 생성 보존 | 기존 알 생성량·확률·주기·보스 조건·SECRET 연결이 유지됨 |
| 위험 표시 | 경고와 실제 피격 위치가 맞고 가장 느린 정상 운반자가 걸어서 피할 수 있음 |
| 멀티 상태 | 장애물 주기·열린 길·넉백·착지·알 상태가 같은 공유 판정을 따름 |
| 화면 가독성 | 작은 모바일 화면과 낮·밤에서 얼굴·큰 알·바닥 경고·출구 방향이 읽힘 |
| 저장 보존 | 기존 소유·운반·드롭 상태가 초기화되거나 알이 복제되지 않음 |

### 반드시 확인할 플레이 상황

- 01~05에서 첫 방문자가 글 설명 없이 후반 목적지를 찾을 수 있는지, 길을 여는 장치가 필수 조건처럼 보이지 않는지 확인한다. 실제 아동 테스트를 하지 않았다면 했다고 쓰지 않는다.
- 모든 맵에서 빈손으로 후반까지 간 뒤 실제 알을 들고 돌아온다. 가장 큰 정상 알 표시와 가장 느린 정상 운반 상태를 포함한다.
- 모든 대표 트롤 지형에서 양방향 진행 중 피격, 양쪽 가장자리 피격, 정상 범위의 강한 넉백을 확인한다. 착지와 경사로가 어떤 방향에서도 연결돼야 한다.
- 기존 배트 규칙으로 알이 드롭되는 경우, 알이 지형 밑·망 구멍·볼풀 장식·벽 안으로 들어가 획득 불가능해지지 않는지 확인한다.
- 일반 접촉으로 통로를 막지 못하면서 배트 넉백은 정상 적용되는지 확인한다. 알을 들었을 때 기존 배트 사용 규칙도 유지되는지 확인한다.
- 한 명이 갈 때 다른 한 명이 알을 들고 돌아오도록 교차 이동한다. 편한 우회로와 안전지대가 충분한지 확인한다.
- 두 명이 같은 선택 지름길을 동시에 열어도 한 번만 작동하는지, 한 명이 귀환하는 동안 길이 닫히지 않는지 확인한다.
- 장애물 작동 중 새 플레이어가 들어오거나 다른 플레이어가 알을 주워도 공유 주기가 갑자기 리셋되지 않는지 확인한다.
- 보스가 새 위치에서 시작하고 기존 입구로 되돌아가지 않는지, 기존 알 획득 조건을 샛길이나 낙하로 우회하지 못하는지 확인한다.
- 경고 시작 시점, 휴식 종료 직전, 배트로 착지한 직후의 상황을 확인한다. 안전지대 전체가 동시에 피격 영역이 되는 조합을 수정한다.
- 지원하는 모바일 화면 크기와 실제 렌더 환경에서 가림·그림자·투명 효과·충돌 비용을 확인한다. 불필요한 동적 파츠를 줄이고 기존 목표 성능을 유지한다.

### 범위를 벗어난 위치의 복구

정상 플레이는 보이는 착지판과 복귀길로 해결한다. 수치 오류나 네트워크 보정으로 맵 밖에 놓인 예외는 기존 복구 체계를 사용해 마지막 유효 보행 영역으로 처리한다. 이 과정에서 운반 알의 소유를 초기화하거나 이미 드롭된 알을 복제하지 않는다. 예외 복구를 정상적인 빠른 귀환 수단으로 만들지 않는다.

## 10. 최종 보고 형식

최종 보고에는 아래 내용만 사실에 근거해 간결하게 남긴다.

1. 수정한 실제 프로젝트 파일과 기존 시스템 연결 내용.
2. 20개 스테이지별 구현 여부, 대표 구조물, 트롤 지형, 보스·알 후반 배치 확인 결과.
3. 실제로 수행한 왕복·운반·배트·멀티·렌더·빌드 확인과 그 결과.
4. 실행하지 못한 확인, 기존 문제와 이번 변경으로 생긴 문제의 구분.
5. 조정한 설계 시작값과 그 이유. 측정하지 않은 프레임·동시 인원·성공률을 만들어 쓰지 않는다.

설명문·가상 스크린샷·미연결 데모만으로 완료 처리하지 않는다. 실제 지형과 기존 시스템이 연결되고, 맵 후반에서 알을 얻은 플레이어가 인터랙트 없이 되돌아오는 흐름을 확인해야 한다.

## 지형과 조형

- 제작안의 A~H 구역별 높이를 정수 칸으로 보관한다. 1칸은 0.16이며, 2~3단 구역은 가장자리부터 낮은 층으로 이어진다. 길 가장자리 단차와 측면 진입 틈은 유지한다.
- 중앙 통로 밖으로 모델 외형을 계산해 배치한다. 알 접근 구역에서는 여백을 더 둔다. 장식은 비충돌이며 기존 외곽 충돌 경계만 사용한다.
- 책은 표지·속지·책등, 선반은 칸막이·개별 책, 상자는 열린 뚜껑·판재로 조형한다. 길이·열림·파손·쌓임 변형을 군집에 사용한다.
- 사막 대표물에 매몰된 얼굴, 신전에 날개 석상, 로봇 조립장에 미완성 몸통·팔, 정원 거목에 금빛 수관·샘을 추가했다.
- 물레방아, 부유 책·조각, 동력 회전부와 일부 생물 군락의 기존 움직임을 연결한다. 화산 외벽에는 비충돌 용암 낙수를 둔다. 계획에 예시로 적힌 모든 소품에 개별 애니메이션을 추가한 것은 아니다.

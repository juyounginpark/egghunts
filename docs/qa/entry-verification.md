# 첫 실행·외형·HUD 검증 (2026-10-03)

사용자의 명시적 검증 요청으로 실행했다. 이전 문서의 미실행 기록 이후 결과다.

## 최종 시작 순서

로고/로딩 → 게스트 또는 로그인 → 이름 → 얼굴/머리/옷/장식 단계별 꾸미기 → 준비됐어! 미리보기 → 탐험 시작 → 저장·월드·탐험가 준비 → 월드 표시 → 700ms 이후 튜토리얼 → 자유 플레이.

최초 로컬 탐험가는 2~4명이며 행동·위치·세션 나이·의사결정 시점을 미리 분산한다. 친구 방에서는 실제 참가자 우선 및 한 자리 여유 정책을 유지한다. 호스트 인계 직후에는 새 탐험가 충원을 12~37초 늦춰 갑작스러운 등장을 막는다.

## 통과한 검사

- build (TypeScript 포함), qa:lint.
- entry-sequence: 지연된 계정 확인/월드 자산 로딩, 단계별 화면, 준비된 월드 이후 튜토리얼.
- mobile-hud: 320/360/390/430px, 접힘/펼침, 효과 아이콘 유지, 중앙 정렬, 친구 입력, 옷장 및 저장 복원, 모의 safe area.
- explorer-rework: 겹친 상자의 표면 제거, 의상/헤어/가방/모자 전후면 갤러리, 헤어 뒤쪽 두피 가림. 검사 모델 최대 830 triangles.
- explorer-profile: ID 카탈로그, 이름, 저장 호환, 외형 delta.
- simulated-players: 5분 시뮬레이션, 약탈/배트, 입퇴장, 인사 응답/무시, 슬롯 및 호스트 인계, 인계 직후 충원 유예.
- local-first: 오프라인 게임 로직, 저장 변환, 시간/보상 제한, cloud revision 충돌, 민감 기능 fail-closed.
- local-first-ui: 오프라인 실행/새로고침, 실제 로컬 WebSocket 친구 연결/보간/이모티콘/호스트 인계, 서버 장애/복구, 모의 Auth/RPC 저장 복원.
- multiplayer 및 balance 개별 검사.

## 검증 중 수정

- 상단 40px 행에 44px 설정 버튼이 겹치던 문제: 행을 44px로 조정.
- 헤어 뒷면 두피와 헤어 사이 틈: 공통 머리 안쪽 덩어리를 보완하고 연결 높이 조정.
- 호스트 인계 직후 즉시 AI 충원 방지.
- 사람이 차지한 슬롯을 제외할 때 위치와 인계 스냅샷에 동일한 필터 적용.
- 실제 야간 귀환과 자연 입퇴장이 독립 테스트 전제를 바꾸던 fixture를 명시적으로 준비.

## 남아 있는 실패와 한계

- 전체 qa:unit은 통과하지 않았다. scripts/test-game.mjs:92의 이전 알 6개 수용량 기대, scripts/qa/unit.mjs:28의 제거된 tickDamage 호출, scripts/qa/progression.mjs:15의 이전 체력 성장 기대가 현재 규칙과 맞지 않는다. 테스트 삭제나 기준 완화는 하지 않았다.
- 브라우저 검사는 Windows Edge/Chromium의 모바일 크기 에뮬레이션이다. 실제 iPhone Safari/Toss WebView/안전영역/FPS를 검증한 것으로 간주하지 않는다.
- Auth/RPC 검사는 fixture이며 실제 이메일 발송이나 다른 실기기의 계정 로그인 확인은 아니다.
- 모든 파츠 조합과 애니메이션에서 깜빡임이 없음을 보증하지 않는다. 외형 갤러리와 표면 계산을 검사했다.
- 일반 상점·알·재화는 여전히 로컬 처리다. 클라우드 revision 검사는 거래 무결성 검증을 대체하지 않는다.

# 20개 지역 검증 기록 (2026-09-23)

## 변경

- 선택 차원에 맞춘 20개 지역의 지형, 소품 군집, 랜드마크, 엄폐물 및 환경 움직임.
- 20개 지역별 수호자 외형, 기존 추적 상태 연결, 호흡·관절 위상차·부유·방향 보간.
- 책, 기차, 톱니, 랩터, 촉수, 전갈 꼬리, 사마귀 낫, 자석, 압축기, 고드름 등 전용 공격물. 회복 단계에서 점진적으로 사라지는 연출.
- 20번 지역의 공허/기억/창조 구간 시각 구분.
- 사용하지 않는 기존 5지역 지형 생성 및 구형 보스 렌더 제거. 기존 농장·카탈로그·저장·HP/회피 규칙 유지.

|---|---|

| qa:regions | 통과: 20개 지역 360×800 캡처, 관절 변화, 모델 존재, 렌더 예산, 반복 전환 자원 안정성 |

| 6뷰포트 캡처·직접 검토 | 통과: 180개 화면, 가로 넘침/조작 영역/체력 표시 검사. 의도한 변경 161개 기준 이미지 갱신 |

| verify | 사용자 요청 **“이미지 비교 패스”**에 따라 시각 비교 중단. 최종 코드의 단위·기본/체력/두 브라우저 E2E와 90개 화면 비교는 통과. 비교를 제외한 나머지 공격·지역·성능·빌드·프로덕션 검증도 통과 |

20지역 측정 최댓값: draw calls 33 / triangles 62,854. 지역당 배치 블록은 2,053~4,770개이며 공유 인스턴스 버퍼로 그린다. 개별 블록마다 Mesh를 생성하지 않는다. 이는 데스크톱 headless Edge/SwiftShader의 렌더링 수치이며 실기기 FPS가 아니다.

## 조사한 실패

- 개발 서버 캡처 중 렌더 소스를 수정해 HMR이 발생한 실행에서 GPU geometry 수 비교 실패. 소스 변경을 끝낸 뒤 재실행해 전환 전후 geometry/texture 수 동일함을 확인했다.
- production E2E가 메뉴 클릭 직후 다음 HUD 프레임 전에 inventory visibility를 읽어 실패. 해당 요소가 보일 때까지 기다린 뒤 기존 동일 assertion을 수행하도록 변경했다. 재실행 통과. 기준 완화나 검사 삭제는 하지 않았다.
- 첫 전체 verify는 E2E와 60개 시각 비교 통과 후, 바다/심해 외형 중복과 남아 있던 공통 공격물 외형을 보완하기 위해 명시적으로 중단했다. 얕은 바다를 해초·부채 조개·조수 웅덩이와 짧은 팔의 우산 문어로 분리하고 시계·석상·도깨비불·증기·물결을 전용 연출로 변경한 뒤 최종 verify를 다시 실행했다.
- 최종 verify의 이미지 비교는 360/390/412px 90개 통과 후 사용자 요청으로 중단했다. 실패를 숨긴 것이 아니며 테스트 코드의 비교 기준·기본 실행 목록은 변경하지 않았다. 따라서 전체 `verify` 통과로 보고하지 않는다.

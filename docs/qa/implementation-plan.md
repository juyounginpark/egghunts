- 20개 지역마다 독립된 20³ 알 조형 5개씩, 총 100개 외형을 사용한다. 색뿐 아니라 실루엣·장식 구조가 다르며 운반·보관·부화에도 외형을 유지한다. 기존 35알/100펫 보상 ID는 유지한다.
- 사용자 스테이지 선택 UI를 없앤다. 농장부터 1→20으로 이동하며 기존 바로가기 저장 위치는 연결 맵의 같은 지역 위치로 옮긴다. 개발 QA의 지역 fixture만 유지한다.
- 180초 주기 중 밤을 45초로 늘리고 실제 환경광·태양광을 부드럽게 낮춘다. 달·별과 낮밤 남은 시간으로 표시한다. 밤에도 탐험/알 회수가 가능하며 같은 밤 재접속으로 둥지를 다시 섞지 않는다.
- 펫은 플레이어 이동 경로를 한 줄로 따라간다. 좌우 분산을 없애고 크기에 맞는 간격, 경로 보간, 부드러운 방향 회전을 적용한다.
- `appearance-e2e`로 100외형 배치, 펫 직진/회전, 낮밤 표시, 선택 UI 제거를 검증한다. 모바일 캡처는 직접 확인하고 사용자 요청대로 기준 이미지 비교는 생략한다.


## 최신 사용자 개정: 연결된 20지역·스피드 성장·잠든 보스 (2026-09-23)

이 절은 아래의 독립 차원 반복 맵, 원정 제한시간, 밤 강제 귀환, 일반 피격 알 유지, 초반 보스 무피해 규칙보다 우선한다.

- 농장에서 앞으로 걸으면 1→20지역이 연결되고, 귀환할 때는 역순으로 통과한다. 사용자 차원 선택은 제거하며 기존 선택 저장은 연결 맵 위치로 변환한다. 일반 지역 길이는 32, 마지막 지역은 150으로 세 구역을 유지한다.
- 20번 지역 끝은 황금 장식의 닫힌 돌벽으로 막는다. 플레이어 이동·넉백 모두 벽 앞에서 멈추며, 지역 바로가기 출발에서도 같은 제한을 적용한다.
- 지역 진입 시 번호·이름·권장 스피드를 3초간 표시한다. 배너는 입력을 막지 않고 공격 예고와 겹치지 않는다. 역방향 진입에도 표시한다.
- 초기 기본 스피드 4.5→3.2. 원정 시간 만료로 실패하지 않으며, 밤은 색 변화·미수집 둥지 갱신만 담당한다. 운반/낙하 알을 빼앗거나 강제 귀환시키지 않고 입구도 막지 않는다.
- 스피드 강화·운동·트레일·펫으로 더 먼 지역을 편하게 탐험한다. 권장 스피드는 이동 거리(둥지까지 약 20초 목표)와 보스 추격 속도/대표 운반 속도 65%에 여유 0.5를 더한 값 중 큰 값이며 최소 3.2다. 시간 제한이나 입장 잠금 수치가 아니다. 원정 시간 강화·시간 특성의 신규 선택 UI는 숨기되 기존 소유값을 삭제하지 않는다.
- 지역마다 수호자 1명과 둥지 알 5개. 수호자는 눈을 감고 Z 표시로 잠들어 있다가 자기 알을 훔치면 분노 표시와 함께 추격한다. 알을 내려놓거나 맞아 놓치면 둥지로 돌아가 다시 잠든다. 재습득하면 다시 깨어난다. 12 거리 밖에서는 원격 공격하지 않는다.
- 보스는 잠든 동안 공격하지 않는다. 환경 장애물은 별도로 유지한다. 초반 보스도 공격 예고 뒤 10~12 피해를 주며, 초반 물살·증기 같은 환경 효과는 무피해를 유지한다.
- 직접 피격은 피해·1초 무적·0.28초 동안 2.4 넉백·알 낙하로 처리한다. 떨어진 알은 해당 위치에 1개만 남고 다시 주울 수 있다. 지속 독 피해는 넉백/낙하를 반복하지 않는다. HP0은 기존 자동 귀환과 70% XP 정산을 유지한다.
- 알의 카탈로그 region, 출처 stageId, 수호자 인덱스를 분리한다. 귀환 보상과 완료 기록은 알의 출처 지역에 적용한다. 기존 35알·100펫·구매·도감 ID를 보존한다. 구 저장의 임시 필드 둥지는 연결 맵으로 재생성하고 운반 알은 보존한다.

검증: `qa:fast`, 이동 기반 `connected-e2e`, 보스 수면/추격/낙하/재습득 `progression-e2e`, 기존 E2E, 42패턴 캡처, 20지역 렌더·GPU 검사, 빌드·성능·프로덕션 E2E. 사용자의 ‘이미지 비교 패스’ 요청으로 이번 실행만 `QA_SKIP_IMAGE_COMPARE=1`을 사용한다. 기본 비교 검사는 변경하지 않는다.

## 체력·레벨·환경 회피 개정

체력 UI 추가 지시: 상단 패널 제거 → 플레이어 좌표를 화면에 투영한 바 → 최대 HP 숨김/피격 표시/회복 숨김 → 360px E2E 위치 검사와 6뷰포트 저체력 화면 검토. 관련 파일 main/world/style/progression-e2e/visual.

1. 데이터/저장 이관: 기존 ID와 강화 보존, level/xp/hp/최초 보상/원정 XP/특성 추가. 공식 경계와 구 저장 테스트.
2. 피해 처리: 1초 무적, 둔화/넉백, 필드 무회복, 알 유지, HP0 단일 실패/70% 정산. 중복 충돌·저장 회귀.
3. 성장/특성: 행동별 XP와 연속 레벨, 6특성 선택/적용. 360px HUD와 기지 선택 UI 검토.
4. 공통 위험/크라켄: 별도 판정 상태 머신, 엄폐/운반 예고 연장, 2패턴. 30/60/120FPS 및 실제 이동 E2E.
5. 안전1~4/확장6~20: 기지 차원 선택, 데이터 패턴/고유 연출, 20단계3구역. 모든 패턴 정의 검사와 대표 장면 캡처.
6. 전체 회귀/성능/빌드: 이전 규칙 충돌 테스트는 최신 명세로 검증 대상을 명시적으로 교체(삭제 금지), fast→E2E→이미지 직접 확인→비교→성능→verify→AIT.

수치/패턴은 data.ts 및 stage-data.ts, 성장은 progression.ts, 판정은 hazards.ts, 연출은 hazard-view.ts에 둔다. 가장 큰 위험은 기존 저장 의미 변화, XP 중복, 짧은 예고와 거대 알의 시야 가림이다.

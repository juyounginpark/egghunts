# 시각 검증 기록

2026-09-23. 결정적 시드/시간/카메라를 고정한 WebGL 캡처와 DOM 검사를 병행했다. Windows Edge 소프트웨어 렌더러 결과이며 실제 iOS/Android 토스 화면 검증은 별도다.

## 범위

360×800, 390×844, 412×915, 1080×1920, iOS 형태 390×844(위 59/아래 34 Safe Area), 320×568. 각 26상태: 기지, 일반/희귀 알 접근, 운반, 긴급 시간, 유실, 부화 온전/균열/순간/결과, 강화, 도감, 밤, 상점, 농장 펫, 튜토리얼, 지역 2~5, 운동, 사망/선택/부활, 펫 관리, 판매.

## 발견한 문제와 수정

| 문제 | 영향/심각도 | 수정 | 검증 |
|---|---|---|---|
| 라벨 배경과 과도한 높이 | 펫·맵 가림/높음 | 패널 제거, 실제 몸체 높이 기준 두 줄, 충돌 위치 조정 | farm-pets 직접 확인 |
| 기지 보관함·도감·상태 정보 과밀 | 이동 방해/높음 | 부화실 보관함, 펫 내부 도감, 5개 하단 메뉴 | base/pets/store |
| 밤 팝업과 불명확한 출구 | 규칙 혼란/높음 | 검은 탐험 장벽, 짧은 상단 시간, 농장 이동 허용 | night 이미지 및 E2E |
| 알 선택 표시가 두꺼움 | 원래 실루엣 소실/중간 | 선택한 알 하나에 얇은 빨간 외곽선 | rare-near 및 대상 ID 검사 |
| 거대 펫 몸체/둥지 크기 | 등급 차이 부족/중간 | 10³~100³ 펫, 알 비례 둥지, 표면 높이에 알 배치 | rare/farm-pets |
| 숫자 소수점 잔여 자릿수 | 조잡한 표시/중간 | 정수 알 HP, 중앙 숫자 포맷, 기존 저장 미세 오차 보정 | store 880/880, 단위 테스트 |
| 재화 1,000에서 헤더 줄바꿈 | 제목·재화 잘림/중간 | 좁은 화면 장식 아이콘 생략, 한 줄 숫자와 고정 설정 버튼 | 360px pets 직접 재확인 |
| 운동 증가가 보이지 않음 | 성장 피드백 부족/중간 | 실제 배율 적용 증가량을 매초 머리 위로 띄움 | training 직접 확인 |

추가로 부활 입자, 모바일 사망 선택, 판매 확인, 가상 광고의 닫기 전/후 화면을 캡처한다. 캡처 전체의 자동 검사는 가로 넘침, HUD 겹침, 버튼 크기/위치, nearest 2배 픽셀 확대를 확인한다. 대표 화면을 직접 검토했으며 156장 모두를 사람이 개별 정밀 검토했다는 의미는 아니다.

## 2026-09-23 체력·환경 공격 개정

- 최신 지시에 따라 상단 체력 패널을 제거했다. 플레이어 머리 위 78px 바는 손상 상태에서만 보이며 완전 회복·부화 화면에서는 숨는다. 숫자 상태는 접근성 progressbar로 제공한다.
- 피격 후 머리 위 위치, 최대 체력 숨김, 귀환 후 숨김을 E2E로 확인했다. 360×800 피격 화면을 직접 검토했다.
- 거대 알에 가려지는 바닥 예고는 깊이 가림 없이 표시한다. 안내 토스트는 조작 버튼 위로 이동했다. 기본 상태 공격 버튼은 없다.
- 20차원 공통 복셀 환경과 41개 공격 정의를 연결했다. 전체 패턴 예고/활성 캡처는 별도 hazard-visual 테스트로 관리한다. 캐릭터 수집 자산은 기존 ID를 보존한다.
- 각 차원의 소품·공격은 공유 복셀 풀을 이용한 MVP 표현이다. 모든 상세 연출이 완성된 최종 아트라고 간주하지 않는다. 특히 압축기 벽의 실제 이동, 랩터의 기절 자세, 공룡의 세 차례 땅 흔들림은 추가 연출 작업이 남는다.

## 이전 검토에서 남은 제작·검증

- 20세계 개별 위험/새로운 140종 구성은 stage-roadmap의 후속 제작 범위다. 현재 기존 5지역·100종 저장을 보존한다.
- 거대 개체가 겹치는 극단 상황과 다수 플레이어/펫의 장시간 실기기 성능은 추가 확인이 필요하다.
- OS별 한글 글꼴 차이 때문에 Windows 기준 이미지와 Linux CI 이미지는 동일 픽셀 비교를 하지 않는다. CI에서는 별도 캡처와 같은 DOM 검사를 수행한다.

# 연결 원정 검증

요구: 걷는 동안 20지역 순차 전환, 진입 배너와 권장 스피드, 낮춘 초기 속도, 원정 시간 제한 제거, 잠든 보스의 절도 후 추격과 피격 알 낙하.

## 검증 결과
- qa:fast: PASS. 20지역 왕복, 출처 보상, 저장, 수면/추격/낙하/재습득, 원격 공격 방지, 마지막 지역 로컬 깊이 포함.
- qa:e2e: PASS. 기존 12시나리오, 보스/성장 3시나리오, 2브라우저 협동 이동, 20지역 실제 이동 왕복·배너·재접속.
- 모바일 배너/경고 화면을 직접 확인하고 겹침을 수정했다. 이미지 기준 비교는 사용자 요청으로 생략했으며 기준 이미지를 갱신하지 않았다.
- Vite 샌드박스 상위 폴더 읽기 오류로 중단된 verify는 권한 승인을 통해 재실행했다.
- 과거의 시간초과/밤 강제귀환/알 유지 테스트는 이번 사용자 규칙에 맞는 보존/낙하 테스트로 교체했다. 첫 네 지역 보스도 실제 피해를 검증한다.
- 시간 강화·시간 특성의 기존 저장값은 남아 있으나 신규 구매·선택 UI에서는 제외했다.

실기기 토스 인증·안전영역·실제 GPU 성능은 별도 검증 대상이다.

## 추가 확인
- 20지역 반복 전환 GPU 검사에서 64→66 증가가 한 번 발생했다. QA 장면 재설정이 RNG를 재설정하지 않아 두 번째 순회에서 다른 알 모델을 처음 GPU에 올린 것이 원인이다. 각 장면 시작 seed를 고정했고 동일한 엄격한 메모리 동등성 검사가 통과했다. 메모리 허용치를 늘리지 않았다.
- 구 원정 저장의 운반 알은 원래 선택 차원을 출처로 보존하는 회귀 검사를 추가했다.
- 마지막 벽 앞에서 전진·넉백이 멈추고 뒤로 이동은 가능한지 시작 지역 1/8/20 모두 단위 검사했다.
- 첫 알 획득 18.6초, 첫 부화 21.1초(결정적 자동 입력 시뮬레이션). 실사용 플레이 시간 보장 수치가 아니다.

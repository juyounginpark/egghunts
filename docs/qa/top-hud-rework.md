# 상단 HUD 리워크 (2026-09-26)

- 첫 행: 기존 캐릭터 썸네일, 레벨·짧은 경험치 바, 오른쪽 정렬 재화·초당 수익, 44px 터치 영역의 작은 설정 아이콘.
- 둘째 행: 낮·밤 상태, 전환 안내, 28px 카운트다운, 3px 남은 시간 바. 크림색·올리브색 패널 유지.
- 기존 게임 시계와 nightAt/nightUntil에서 계산하며 별도 카운터를 사용하지 않는다. 기존 설정의 낮 285초·밤 15초를 각각 분모로 사용한다. MM:SS 및 HH:MM:SS 지원.
- 밤 진입 10초 전만 주황색과 1회 짧은 강조를 사용한다. 모션 감소 설정에서는 강조 애니메이션을 생략한다. 아침 전에는 밤 색상을 유지한다. 타이머의 aria-live는 off다.
- 알 획득 공지는 투명 배경·가운데 정렬로 변경했다. 관찰된 낮 전환에는 리셋 안내를, 실제 월드에 있는 SS 이상 알에는 스테이지·등급·알 이름을 같은 양식으로 표시한다. 공지는 전체 상단 HUD 아래에 배치한다.
- 저장 형식, 획득 확률, 생산량, 낮·밤 지속 시간은 변경하지 않았다.

사용자가 이번 요청에서 화면 및 상태 확인을 명시하여 아래 검사를 실행했다.

- `npm.cmd run qa:typecheck`: 통과.
- `node scripts/qa/hud-rework.mjs`: 통과.
- Edge 브라우저의 320·360·390·430 CSS px에서 낮·밤 직전·밤·1시간 이상/긴 재화 표기 총 16개 조합. 레이아웃 범위, 겹침, 설정 터치 영역, 시간·남은 비율, 경고 상태 확인.
- 320px에서 K/M/B/T/Qa 재화 표시와 설정 버튼의 영역 분리 확인.
- 실제 GameState 전환을 진행해 밤 00:15 → 낮 04:45, 각 시작점 시간 바 100%, 이전 밤 안내 숨김 확인.
- 시간 포맷의 음수 0 처리와 시간 단위 전환, 브라우저 pageerror 없음 확인.
- 생성한 390px HUD 캡처에서 낮 전환 임박/밤의 배색·정렬을 직접 확인했다.

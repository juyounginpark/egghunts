탐험은 부화 재료, 부화는 성장 재화와 동행을 제공해 서로 필요하다. 낮은 능력의 먼 지역 실패는 왕복 시간·운반 중 감속·기존 보스 추격에서 발생하며 강제 실패는 추가하지 않는다. 첫 10분 목표는 시뮬레이션으로 확인하고 확률 획득을 보장으로 표현하지 않는다. 독자 명칭·직접 설계한 AIvoxel 자산을 유지하며 유사 게임의 외형이나 수치를 가져오지 않는다. 실기기에서 엄지 도달성과 멀미·조작성 검증은 별도로 남긴다.

공식 SDK 확인: [점수 API](https://developers-apps-in-toss.toss.im/documentation/sdk/domains-api/game/game.setleaderboardscore), [서버 시간](https://developers-apps-in-toss.toss.im/documentation/sdk/domains-api/environment/environment.getservertime). 설치 SDK 타입과 함께 검토하며 실제 네이티브 연결 성공을 자동 테스트로 대신 주장하지 않는다.

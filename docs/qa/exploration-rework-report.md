# 20단계 탐험 리워크 적용 기록

## 구현 연결

- `src/exploration-route.ts`: 20개 본길의 누적 거리, 우회·착지·경사·빙판·벨트 영역, 후반 알 앵커와 선택 장치 좌표.
- `src/exploration-layout.ts`, `region-layout.ts`, `region-art.ts`, `map-collision.ts`: 실제 인스턴스 지형과 충돌체. 기존 무작위 직선 도로 장식을 대체한다. 플레이어 지면 충돌 지름은 0.48이며 본길 폭 4.4, 우회로 폭 4, 대표 발판 폭 3.8로 넓혔다. 표면 높이를 로컬·원격 캐릭터, 동행 펫, 알, 보스에 적용한다.
- `src/game.ts`, `stage-data.ts`: 기존 101개 알·21개 보스의 수/종류/확률을 유지하고 일반 보스 72%, 최종 추가 보스 81%, 알 90~95% 근처에 배치한다. 시뮬레이션에서 전부 보스 60~85%, 알 85~100% 범위에 들어감을 확인했다.
- `hazards.ts`, `hazard-view.ts`: 공용 시각의 경고·작동·휴식, 고정 횡단, 3.2폭의 레이저/공허 빈칸. 1~5 환경 피해 0, 후반 8% 기준. 기존 보스 피해·배트 수치는 보존한다.
- `server/room-engine.ts`, `online.ts`: 거리·빈손 판정의 지름길 명령 및 방 전체 개방 상태, 서버 속도 획득 판정. 기존 드래곤 관찰 키를 저장 검사에서 계속 허용한다.
- `exploration-migration.ts`: 자연 둥지 점유 알만 후반으로 이동한다. 떨어뜨린 알 좌표·ID와 운반/보관/소유 데이터는 초기화하지 않는다.

## 수행한 확인

- 타입 검사 통과. 첫 검사에서 새 안내 변수와 기존 `near`의 이름 중복을 고친 뒤 통과했다.
- `node scripts/qa/exploration-rework.mjs`: 20개 본길 왕복·운반 중 충돌 통과, 미달 획득 거부/체력 유지, 획득 후 스탯 감소에도 소유 유지, 배트 착지와 복귀, 101알/21보스 후반 위치, 드롭 보존, 두 플레이어 지름길 공유/중복 개방, 공용 장애물 시간, 빈칸 판정 통과.
- `node scripts/qa/exploration-rework-ui.mjs`: 390×844 브라우저에서 20단계 낮/밤 렌더와 자산 오류 없음, `필요 속도 1.1K / 현재 850` 표시, 실제 지름길 버튼 클릭 통과. 첫 실행은 보스 첫 방문 안내 모달 때문에 클릭이 차단되어 실패했고, 재실행은 안내를 확인한 이용자 상태로 검사했다. 실제 게임의 안내를 제거하지 않았다.
- 위 브라우저 표본은 최대 40 draw calls, 46,470 triangles. 브라우저 렌더 표본이며 실기기 FPS 측정이 아니다. 이미지와 상세 지표는 로컬 `artifacts/exploration-rework/`에 저장한다.
- Pages용 클라이언트 빌드 및 서버 배포 번들 생성 성공.
- 서버 배포: 코드·데이터를 `/opt/egghunts/backups/pet-replace-20260926T182844Z`에 백업한 뒤 적용했고 서비스 active를 확인했다.
- 빌드 출력의 전체 JS 청크 gzip 합은 약 331.3kB로, 기존부터 초과하던 300KiB 전송 예산은 여전히 초과한다. 초기 네트워크 전송량 전체를 실기기에서 측정하지 않았다.

## 미확인·한계

- 실제 두 기기의 동시 온라인 이동·배트·재접속 플레이와 토스 실기기, 아동 사용자, 모든 방향 최대 넉백, 가장 큰 알의 전 구간 가림은 확인하지 않았다. 서버 두 명 검사는 모의 상태 검사다.
- 왕복 경로 검사는 충돌/소유 판정 시뮬레이션이다. 장애물을 모두 피하는 플레이 성공률이나 난이도를 측정하지 않았다.
- 기존 절대적인 낮/밤 길이, 알 무게, 경제를 유지한다. 50K 목표값을 한 달에 도달하도록 비용·획득량을 조정한 결과가 아니다.
- 지형은 기존 XZ 충돌 체계에 높이 표면을 연결했다. 새 점프·중력·동적 물리 엔진을 넣지 않았다.
- 기존 전체 QA는 새 목표값/좌표 이전의 기대치를 포함한다. 삭제하거나 완화하지 않았으며 이번 연결 검사 외 전체 QA 통과를 주장하지 않는다.

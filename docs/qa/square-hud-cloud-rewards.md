# 정사각형 HUD와 기본 저장 연결 (2026-10-03)

- 기본 HUD 버튼은 정사각형 + 이모지 + 필요한 숫자로 표시한다. 참가자는 `👥`와 인원수만 표시하며, 누르면 이름·지역·속도 목록을 펼친다.
- 접은 시계는 64×64이며 카드 전체로 펼친다. 옆 V 버튼은 제거한다. 설정·감정표현·운동·행동·가방·하단 메뉴에도 이모지를 적용하고 접근성 이름을 유지한다.
- 확인/구매/로그인 등 상세 화면의 문장형 버튼은 기능을 식별할 수 있도록 유지한다.
- 게임 시작 시 기존 인증 세션을 재사용한다. 처음 시작하는 게스트는 익명 인증 후 자동 업로드하며, 네트워크 복구 또는 저장 주기에 재시도한다. 기존 계정 인증을 잃었을 때는 새 익명 계정으로 바꾸지 않는다.
- 친구 Presence 연결은 선택 사항이다. 기본 진행 저장은 Supabase Auth + `game_local_profiles`를 이용한다.
- 주간 보상은 미연결 SecureEconomy 임시 호출 대신 `game_local_claim_weekly` RPC를 사용한다. 먼저 로컬 진행을 동기화한 후 서버 날짜로 수령 가능 여부를 판단한다. 보상과 프로필 revision은 같은 트랜잭션으로 반영한다.
- `game_weekly_claims`는 일반 세이브와 별도로 수령 횟수/날짜를 유지한다. 기존 출석 데이터는 최초 수령 시 이어받는다. 통신 응답이 유실되면 서버 revision을 다시 확인하며, 충돌 데이터를 무조건 덮어쓰지 않는다.
- 일반 재화/성장 값은 여전히 로컬 기반이므로 변조 방지가 완성된 경제 시스템은 아니다. 결제/쿠폰/리더보드는 이번 변경에 포함하지 않는다. SQL 보상 상수는 balance.ts/data.ts/weight.ts 변경 시 함께 갱신해야 한다.

## 확인 범위

- 사용자 작업 규칙에 따라 자동 QA·스크린샷·로컬 검증 빌드는 실행하지 않았다.
- Supabase 마이그레이션 `202610030002` 적용 완료. 브라우저 실수령/모바일 배치 검증은 미실행이다.
- 프런트엔드 배포는 main 푸시 후 기존 GitHub Pages 배포용 CI를 이용한다.

## 수동 확인 항목

- 320px~430px 화면에서 시계/탐험가 정사각형, 전체 카드 클릭, 상세 접기, 하단 버튼 간격 확인.
- 신규 게스트 자동 클라우드 저장, 오프라인 시작 후 재연결, 기존 계정/저장 보존 확인.
- 주간 보상 첫 수령, 같은 날 재수령, 7일차 알, 보관함 가득 참, 저장 충돌, 응답 유실 후 재시도 확인.

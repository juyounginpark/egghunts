# 탐험가 준비실과 단계별 생성

## 구현

- 첫 생성: 게스트/로그인 → 이름과 준비실 미리보기 → 얼굴 → 머리 → 옷 → 장식 → 전신 완성 → 탐험 시작. 각 단계는 이전/다음으로 이동하며, 필수 선택 없이 현재 모습으로 완성 가능하다.
- 최초 생성은 카테고리 탭을 숨기고 현재 단계만 표시한다. 기지 옷장에서는 네 카테고리를 자유롭게 이동한다. 세부 항목도 한 번에 하나만 편집한다.
- 프리셋은 좌/우 버튼과 이름·번호, 색은 터치 영역 44px 이상의 swatch로 선택한다. 이미지/게임 외형은 기존 복셀 재질과 큰 색면을 활용한다.
- 카메라는 340ms 전환. 얼굴 ±20도, 머리 ±45도, 의상·장식은 전신 회전. 가방은 약 166도 후면으로 전환하며 다음 가방 선택 시 방향을 유지한다.
- 준비실: 거울, 원목 옷장, 행거, 접힌 옷, 스툴, 모자 선반, 가방, 지도, 나침반, 랜턴, 화분, 여행 가방, 부츠, 액자, 창문, 러그, 나무 상자. 반사는 하늘색 면이며 별도 반사 렌더링을 하지 않는다.
- 깜빡임, 작은 고개/몸/발 움직임, 짧은 표정 변화, 의상 선택 시 팔 벌리기, 완성 시 손 흔들기. 모션 줄이기 설정에서는 애니메이션을 생략한다.
- 기지 입구 오른쪽 옷장/거울: 위치 (4.8, -1.8), 접근 반경 1.8. 월드 모델과 충돌은 동일 블록을 사용한다. 꾸미기 저장/취소와 재입장 지원.
- 접힌 시계 HUD는 64×64, 카드 전체 클릭. 참가자 그림 버튼과 다른 HUD 디자인은 유지한다.

## 카탈로그

| 구분 | 수량 |
| --- | ---: |
| 피부 | 10 |
| 눈 / 눈썹 / 입 / 볼 | 12 / 8 / 10 / 8 |
| 머리 / 머리색 | 18 / 12 |
| 의상 / 포인트색 | 13 / 10 |
| 머리 / 얼굴 / 목 장식 | 12 / 8 / 6 |
| 백팩 | 8 (처음 4종) |

기존 헤어·의상 ID를 삭제하지 않아 요청 예시보다 일부 종류가 많다. 백팩은 기본/캠핑/알/미니가 처음 제공된다. 숲/바다/동물/우주 가방은 최고 단계 5/9/13/17에서 선택할 수 있다. 이미 보유한 선택은 단계가 낮아도 편집기에 유지한다. 소지품은 향후 미리보기 전용 타입만 준비한다.

## 저장·멀티플레이·성능

- faceId/accessoryId는 호환 필드로 보존한다. 누락된 세부 얼굴/장식만 이전 선택에서 파생한다. 기존 피부·머리·옷·색·백팩 ID를 재배열하지 않는다.
- 원래 로컬/클라우드 세이브에 ID만 저장한다. 외형으로 능력치·물리·경제를 수정하지 않는다.
- Human/AI/Remote 모두 같은 normalizer/model. AI는 일반 머리색/헤어/의상을 더 자주 선택하고 성격·진행도에 따라 장식 후보를 조절한다. 동시 참가자와 완전히 같은 외형은 최대 세 번 다시 선택한다.
- Presence 서버의 ID 범위를 확장하며 이전 클라이언트의 누락된 신규 슬롯을 허용한다. 외형 변경은 즉시 delta 후보이고, 일반 위치 업데이트에는 외형을 반복해서 넣지 않는다.
- 큰 색 블록은 뼈대 파츠별 병합. 눈/입은 미리보기 표정용 두 메시이며, 준비실은 단일 메시다. 신규 기지 옷장은 기존 지형 메시 안에 합친다. GPU/FPS 예산 충족은 실측하지 않았다.

## 확인 범위

- 사용자 규칙에 따라 자동 QA, E2E, 스크린샷, 로컬 검증 빌드는 실행하지 않았다.
- 수동 실행용 `explorer-profile`, `mobile-hud`, `local-first-ui` 시나리오를 새 단계/카탈로그/레거시 호환에 맞췄다. 실행/통과를 의미하지 않는다.
- 배포는 기존 Pages CI 빌드와 EC2 Presence 번들을 사용한다. 배포 결과는 최종 응답에서 구분한다.
- 실기기 Safari/Toss, 모든 파츠 조합의 겹침, 얼굴 확대 가독성, 옷장 접근 동선, 두 기기 외형 변경/호스트 이전은 별도 확인이 필요하다.

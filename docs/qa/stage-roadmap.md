# 20개 세계 디자인 계약과 출시 전환안

> 최신 맵 개정: 일반 구간 96, 최종 구간 450으로 3배 확장한다. 각 지역은 15종 지형 요소, 회전·기울기·크기 변화, 연속 좌우 벽을 갖는다. 위험 요소는 1~4단계 1개에서 17~20단계 5개로 증가하며 각 스테이지 전용 목록과 고정 위치를 사용한다. 과거 길이·위험 수·피해 기준보다 기획서 최상단 개정이 우선한다.

> 최신 펫 개정: 20개 스테이지는 서로 다른 전용 펫 10종씩 총 200종(ID 100~299)을 가진다. 기존 100종(ID 0~99)은 이전 도감과 저장 기록을 보존한다. 신규 알은 출처 stageId의 펫만 부화한다. 새 카탈로그는 `src/stage-pet-catalog.ts`, 제작 원본·생성기는 `scripts/generate_stage_pets.py`다. 각 스테이지는 C/B/A 각 2종, S/SS/SSS/Secret 각 1종이며 아래의 7종 출시안보다 우선한다. 자동 검증은 실행하지 않았다.

> 최신: 지역은 거리로 연결되며 사용자 차원 선택은 제거했다. 지역별 알 5개씩 총 100외형, 펫 한 줄 추종, 45초 밤을 적용했다. 초기 스피드 3.2, 제한시간 없음, 수면→알 절도→추격→피격 알 낙하. 루트 기획서 맨 앞 개정이 아래 이력보다 우선한다.

## 최신 전투 없는 원정 개정

2026-09-23 지역 시각 구현: 최신 순서의 20개 차원별 지형·소품·수호자 모델을 추가했다. 구현 범위와 검증은 [region-implementation.md](region-implementation.md)를 따른다. 아래의 5지역 실행판 설명과 최초 공개안은 이전 카탈로그 전환 기획의 이력이며, 현재 선택 가능한 맵 수를 뜻하지 않는다.

아래 이전 표는 디자인 이력이다. 실제 선택 차원 순서/공격은 루트 기획서 앞부분의 `최신 개정: 체력·경험치·환경 회피` 및 `src/stage-data.ts`를 우선한다. 5에 크라켄을 추가하고, 20은 공허의 길/기억의 정원/창조자의 문으로 통합했다. 기지에서 차원을 선택하며 기존 카탈로그 35알·100펫 ID와 수집 이력은 그대로 보존한다. 차원마다 신규 7종을 제작했다는 의미는 아니다.

사용자 지정 SECRET 디자인 이력도 보존한다: 몽글 초원=사계절 사슴(걸을 때 주변 계절 변화), 장난감 왕국=왕관 태엽곰(태엽을 감으면 다른 몽글이가 춤), 심해 산호숲=심해별 고래(몸 안 별과 물고기). 아직 전용 자산/능력 구현을 뜻하지 않는다.

상태: 사용자 제안의 상세 제작 기획. 아래 20개 세계가 전부 구현됐다는 의미가 아니다. 현재 실행판의 5지역·100종 ID와 세이브는 유지한다. 최초 공개 4지역·28종·12알 외형으로 바꾸려면 구 도감 보관 탭과 ID 마이그레이션을 먼저 검증한다. 이미 얻은 펫·보상·장착 슬롯을 삭제하거나 새 게임으로 초기화하지 않는다.

## 공통 문법

- 각 지역은 대표 색 두 개, 고유 지면 구조, 세 가지 알 실루엣, 방해 요소 한 개, 고유 신체 구조를 가진다. 같은 나무를 다른 색으로 칠한 지역은 승인하지 않는다.
- 지역당 C/B/A/S/SS/SSS/SECRET 각 1종, 7종. 등급과 알 외형을 분리한다. 알 외형 3종은 C~B / A~SS / SSS~SECRET에 배정하고 크기·왕관·빛으로 등급을 구분한다. 확률 45/28/15/7/3.5/1.3/0.2%는 그대로 유지한다.
- 작은 펫 10³, 가장 큰 펫 100³까지. 격자 차이만 늘리지 않고 발 수·몸 분절·공중 빈 공간·부속기관의 수를 달리한다. 100³는 AIvoxel의 50³ 이하 부분 모델을 합친다.
- 지형 장식은 덩어리 배치, 빈 공간, 대표 랜드마크를 조합한다. 좌우 대칭 반복과 일정 간격 소품 행렬을 금지한다. 플레이 가능한 길 폭과 보스 예고 범위는 장식보다 우선한다.
- 각 벽은 아래 표의 지형 재료를 쓴다. 연결부 마지막 10% 구간에 다음 재료가 섞이고, 관문을 넘어가면 바닥 구조와 환경음도 바뀐다.

## 해금·예고·엔딩

1~4 자연계 → 5~8 문명/과거 → 9~12 신화/초과학 → 13~16 비현실 → 17~20 세계의 진실. 미공개 포털은 검은 실루엣과 단계 번호만 보이고 입장 버튼을 제공하지 않는다. 도감 미발견은 이름·능력·이미지를 `???` 처리한다. 업데이트는 출시 후 2주당 1지역을 목표로 하되 제작/성능/QA 완료가 먼저다. 자동 출시나 날짜 확약은 하지 않는다.

19에서는 배경음·환경음·배경 채도를 줄이되 공격 예고와 필수 UI 대비는 유지한다. 접근성 때문에 위험 신호까지 완전히 무음·무채색으로 지우지 않는다. 20의 입장 순간에는 19개 세계의 색 조각이 흰 바닥을 순서대로 채우고, 플레이어가 선택한 모자 색이 마지막 꽃을 물들인다. 장시간 파티클 대신 짧은 인스턴스 연출 후 안정된 흰색·금색 정원으로 돌아온다.

## 체력과 성장 계약

피해는 고정 피해 + 최대 HP × 비례 계수. 일반 비례 3~8%, 최종 단계의 강한 공격만 20% 상한. 성장으로 피해가 0이 되는 방어식은 넣지 않는다. 속도는 거리/회피 여유, 체력은 실수 허용량, 플레이 실력은 예고 회피, 조합은 한 위험의 완화를 담당한다. 조합 보너스가 위험을 완전히 제거하지 않게 한다.

현재 실행판: 최대 HP 100 + 강화당 20, 3초 미피격 후 초당 최대 HP 4% 회복, 기지 도착 전량 회복. 보스 예고 0.65초, 피격 시 알 즉시 낙하. 지역별 환경 방해와 조합 저항은 다음 제작 단계이며 현재 구현 완료로 표시하지 않는다.

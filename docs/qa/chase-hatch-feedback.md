# 부화실·추격·피격 피드백 변경

- 낮 전환 시 `낮이 되었어요! / 알이 리셋되었어요!`를 획득 배너 형식으로 표시한다. SS·SSS·Secret 알은 해당 방의 실제 월드 목록에서 읽어 지역 번호·이름·등급·알 이름을 공지한다. 같은 알 종류는 수량으로 합치고 높은 등급부터 표시한다. 접속 시 현재 희귀 알도 안내하며, 이미 가져간 알은 표시 차례에서 제외한다. 밤에는 이전 출현 공지를 비운다. 원격 공지 전송을 추가하지 않고 기존 권위 서버 스냅샷을 사용한다.
- 알 획득·희귀 알 출현·낮 전환 배너는 화면 상단 중앙에 배치하고 배경·테두리·그림자 박스를 없앴다. 글자는 밝은 색과 텍스트 그림자로 구별한다. 자동 검증·스크린샷은 실행하지 않았다.

- 실시간 스냅샷 복원에서 옛 스테이지 순열 변환을 제거했다. 버전이 없는 서버 프레임을 5→19로 변환하던 경로와, 접속 시 서버 스냅샷을 생성자에서 직접 변경하던 경로를 분리했다. 저장된 방·프로필의 최초 마이그레이션은 유지한다.
- 부화실 망치 버튼과 보관함의 별도 획득 버튼을 숨기고, 3D 알의 투영 영역과 아래 문구를 눌러 두드리거나 개봉한다. HP가 0일 때만 개봉하며 서버 소유권 확정 후 연출한다.
- 기존 부화대에서 약 1초 가속 회전 → 등급색 파편과 충격파 → 같은 위치에 펫 등장 → 2.7초 후 획득 UI 순서다. 에셋 로딩 실패 시 획득 UI로 진행하며 재지급하지 않는다. 모션 감소 설정과 저사양 입자 수 제한을 반영했다.
- 알 획득 이름·등급 안내는 화면 아래에 배치하고 카메라가 안내 위의 공간을 사용한다. 운반 표시는 화면 높이 39% 위치에 배경 없는 `알 운반중` 문구다.
- 보스는 공격 반경 바깥 3m까지 급속 접근한다. 먼 거리에서는 스테이지·플레이어 성장 스탯과 관계없이 최소 48, 최대 120의 접근 속도를 쓰며, 이탈 속도와 남은 거리에 따라 가속한다. 한 틱의 이동을 목표 거리에서 잘라 공격 범위까지 돌진하지 않게 한다. 가까워진 뒤에는 기존 근접 추격 속도를 사용한다. 각성·공격 판정·밀치기·알 낙하 규칙은 유지한다.
- 보관소는 알이 없어도 하단 6칸을 모두 표시한다. 선택 알의 현재/최대 HP와 다음 클릭의 예상 감소량을 표시하고, 클릭 성공 이벤트에 실제 차감량을 담아 `−피해량` 숫자·파편·알 흔들림을 재생한다. 자동 부화 피해와 클릭 피해를 합쳐 표시하지 않으며, 마지막 타격은 남은 HP만큼만 표시한다. 온라인 실제 차감 연출에는 갱신된 서버 이벤트가 필요하다.
- 통행 구역의 복셀 조형 장애물, 엄폐물, 지상 흔들림 오브젝트와 공격 발생 구조물을 1.5배로 확대했다. 빨간 윤곽선은 인스턴싱으로 합친다. 공유 레이아웃과 발생 구조물 충돌 크기도 함께 확대한다. 바닥·배경벽·공중 장식 및 공격 범위·피해량은 확대하지 않는다.
- 타격 총 피해량을 0.15초 간격 6회로 나눴다. 피격 무적·상태이상·밀치기는 즉시 시작한다. 남은 피해는 원정 저장과 서버 런타임에 보존되며, 기지 회복·귀환·부활 시 제거된다. 마지막 버티기와 사망은 실제 HP가 0에 도달하는 틱에서 처리한다.
- 최초 공격 원점 방향을 플레이어 주변 빨간 화살표로 1.4초 표시한다. 도트 틱은 방향 표시를 재발생시키지 않는다. 잃은 HP 비율에 따라 붉은 비네트가 연속적으로 진해진다.

## 검증 및 배포 상태

프로젝트 규칙에 따라 이번 변경의 자동 테스트·빌드·스크린샷은 실행하지 않았다. 수동 실행용 `node scripts/qa/chase-feedback.mjs`를 추가했다. 기존 QA는 삭제하거나 비활성화하지 않았다. 즉시 HP 차감을 전제로 한 기존 전투 QA는 새 도트 피해 타이밍을 반영하는 후속 검토가 필요하다.

실기기에서 알 투영 클릭 영역, 짧은 화면의 문구 간격, 7등급 연출과 여러 장애물의 윤곽선 밀도를 확인해야 한다. 기존 성능 예산 준수는 이번 변경에서 측정하지 않았다.

공개 EC2 서버 재배포는 이번 작업에서 수행하지 않았다. 온라인 보스 추격·도트 피해·공격 원점·확대된 충돌 및 이전 카탈로그 개편은 동일 버전 서버 배포가 필요하다. 클라이언트 푸시만으로 서버 로직이 변경되지는 않는다.

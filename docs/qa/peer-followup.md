# 동행·운반 알·이동 후속 — 2026-09-24

## 변경

- 서버 peer 목록에 activePets, 서버 시각, 현재 speed를 추가했다. 농장 표시 목록과 동행 목록을 분리한다. 장착과 알 선택 명령은 revision을 갱신한다.
- 상대 펫은 자기 펫과 같은 경로 추종 함수를 사용한다. 비동기 로드 세대 검사로 해제/퇴장 뒤 이전 모델이 다시 생기지 않는다.
- 상대 알의 흰 큐브는 aura 인스턴스가 단위 행렬로 남아 있던 문제였다. 생성 즉시 초기화하고 원격 알에도 매 프레임 효과 애니메이션을 적용한다.
- 상대 플레이어는 리그 모델을 사용하며 실제 표시 이동에 따라 걷기, 정지, 운반 팔 자세를 적용한다. 서버 위치는 GuardianMotion 버퍼를 재사용한다.
- 자신의 이동 중 위치 보정은 고정 최대 보정 속도만 쓰던 방식에서 오차에 비례한 감쇠로 변경했다. 서버 판정은 그대로다.
- 기지 고정 1.6을 제거하고 현재 속도를 적용한다. 방 진행도 표에도 서버가 계산한 현재 스피드를 표시한다.
- 알 HP 0은 보관소 준비 완료 상태다. claimHatch에서만 펫/별가루를 지급한다. 획득 공개는 확대/맥박/균열/실루엣/실제 모델 회전이며 건너뛰어도 지급은 중복되지 않는다. 귀환 알 획득 공지는 방에 최대 60초/30개 보관하고 클라이언트에서 ID 중복을 제거한다.

- 새 부화 연출/공지/스피드 표의 모바일 스크린샷 검수는 미실행. 두 브라우저 fixture를 실제 공개 방의 2인 플레이로 간주하지 않는다.

## 실제 Supabase 게스트 이동 측정

자료: `artifacts/performance/live-movement-peer-followup.json`, `live-movement-peer-smooth.json`. Windows headless Edge, 390×844, 정상 네트워크. 실제 휴대폰 FPS가 아니다. 두 실행의 서버 지연과 방 상태는 동일하지 않다.

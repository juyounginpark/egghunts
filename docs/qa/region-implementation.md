# 20개 탐험 지역 구현

최신 기획서의 1~20 차원이 실제 탐험 지형을 결정한다. `region`은 기존 알·펫 카탈로그 호환용이며 차원 수가 아니다. 농장은 공통 출발점이다. 기존 저장의 35알/100펫 ID는 변경하지 않았다.

`region-art.ts`는 지역별 지면, 외곽 구조, 비대칭 소품 군집, 랜드마크, 엄폐물, 환경 애니메이션을 인스턴스 배치한다. `region-guardian.ts`는 현재 선택 지역의 보스 외형을 기존 수호자의 이동 상태에 연결한다. 예고·피해 판정은 기존 `hazards.ts`가 담당하고 `hazard-view.ts`가 공격물의 준비·발동·회복을 표현한다. 공격 버튼은 추가하지 않았다.

움직임은 시간 기반 호흡·부유·부속기관 위상차, 기존 추적 상태에 따른 보행, 지수 보간 방향 전환을 사용한다. 환경 장식과 보스는 피해를 중복 판정하지 않는다. 통행 가능한 중앙 지면을 유지하고 기존 엄폐 판정 위치에 시각 엄폐물을 배치한다. 복셀마다 Mesh를 생성하지 않는다.

검증: `npm run qa:regions`는 20개 지역 모바일 화면, 모델 존재, 렌더링 예산, 짧은 시간 간격의 관절 변화, 반복 지역 전환의 GPU 자원 수를 확인한다. 캡처는 `artifacts/screenshots/regions/`, 결과는 `artifacts/test-results/regions.json`. 전체 회귀는 `npm run verify`에 포함된다.

범위: 지역별 신규 알·펫 카탈로그 제작은 포함하지 않는다. 보스는 공격해서 쓰러뜨리는 전투 대상이 아니라 알을 지키고 환경 공격을 예고하는 수호자다. 최종 3구역의 공격 단계 전환과 지면 색·구성품 전환은 기존 거리 경계를 따른다. 실기기 토스 WebView의 FPS·햅틱·인증은 별도 검증 항목이다.

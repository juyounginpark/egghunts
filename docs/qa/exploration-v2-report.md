## 시작값과 전후 관측

- H_s=100, A_s=3 고정. 개인 최대 체력을 다시 곱하던 환경 피해 대신 고정 정수를 적용해 체력 성장 효과를 보존한다. 이것은 실측 한 달 밸런스 결과가 아니다.
- 기존 12단계 관측에서는 활성 1.2초/단발이었다. v2는 예고 2.4초/활성 1.8초/휴식 4초로 공용 시각에서 계산한다. 기존 1초 피격 무적을 유지하기 위해 문서의 0.75~0.8초 틱은 1.05초로 조정했다.
- 움직이는 위험의 렌더와 판정은 같은 궤적을 사용하고, 프레임 사이 이동은 이전 100ms 이내 구간을 샘플링한다. 내려찍기는 마지막 예고 구간에 실제로 내려오고 복귀 구간에는 피해를 주지 않는다.
- 기존 즉시 지름길 해제 대신 개방 상태를 공유하고 650ms 후 충돌을 해제한다. 돌아오는 플레이어의 필수 입력은 추가하지 않았다.
- 자동 화면 확인 중의 하얀 안개는 QA 고정 시각에 따른 미완료 페이드였으며 게임 안개를 제거하는 방식으로 수정하지 않았다.

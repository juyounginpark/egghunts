# 첫 알 경험 개편

목표는 첫 보상을 설명보다 행동으로 익히게 하는 것이다. 새 계정만 안내하며 완료·건너뛰기 기록을 되돌리지 않는다. 타이머로 진행시키지 않고 실제 행동 이벤트로 진행한다.

| 묶음 | 안내 | 조작 강조 | 완료 기준 |
|---|---|---|---|
| 1 | 첫 알을 만나러 | 조이스틱 | 농장 밖으로 이동 |
| 2 | 알에 다가가기 / 알 가져오기 | 조이스틱 → 획득 버튼 | 실제 알 획득 |
| 3 | 농장으로 돌아오기 | 조이스틱 | 알 보관 완료 |
| 4 | 보관한 알 열기 → 선택 → 톡톡 → 개봉 | 부화실 탭 → 슬롯 → 알 | 실제 펫 획득 |
| 5 | 첫 성장 | 강화 탭 → 강화 선택 | 첫 강화 구매 |

- 화면에 한 제목·한 짧은 문장만 노출한다. 기존 보스 안내와 결과 연출 중에는 중복 안내를 숨긴다.
- 밤에는 카운트다운을 안내한다. 알을 잃으면 획득 행동을 다시 안내하고, 부화 전 알을 모두 판매한 경우 탐험을 안내한다.
- 안내 닫기는 기존 저장 단계 5로 처리한다. 먼저 트레일을 사거나 부화 전 강화했다고 튜토리얼을 완료하지 않는다.
- 1단계 C 알: HP 12 / 기본 피해 3 = 자동 생산·펫 효과 제외 4클릭. 2~4단계 C 알은 24/45/80. 이후 단계별 곡선과 등급 배율은 src/data.ts의 EGG_HEALTH와 eggMaxHp를 사용한다.
- 기존 저장 알의 남은 비율을 v3으로 변환한다. 예: 1단계 C 알 150/300 → 6/12, 완료 알 0 → 0. 실제 ID와 선택 상태는 유지한다.
- 피해 숫자는 서버/로컬에서 승인된 실제 감소량만 클릭 지점에 표시한다. 키보드 입력은 알 중앙을 사용한다.
- 보관함은 그림·등급·빈 슬롯·수량, 체력과 손가락 아이콘/피해 숫자로 정리한다. 접근성 이름은 유지한다. 알 공지에서 알 그림을 제거한다.
- 알 터치 안내는 비대칭 모델 경계가 아닌 화면 중앙을 기준으로 정렬한다.
- 닉네임 이름표는 물리 픽셀 정렬, 단일 이동 레이어, 불투명 배경으로 변경했다. 제보한 잔상은 실기기 재현 및 해결 확인이 남아 있다.

자동 테스트·타입 검사·빌드·스크린샷은 이번 요청에서 실행하지 않았다. 저장 변환 수동 검사 코드는 갱신했다. 온라인 체력/튜토리얼 조건은 서버 배포 후 적용되며, 이 작업에서 EC2 배포는 하지 않았다.

- [비교 갤러리](index.html), [20개 플레이 화면](play/contact-sheet.png), [20종 드래곤](twenty-dragons.png), [전후 비교](before-after.png), [알 대응](egg-hatch-correspondence.png).
- `stage-integration`: 9개 검증 통과. 기존 100/300/320종 저장·소유·편성·판매 이력, 확률 경계, 서버 검증, 220개 모델의 고유 형상·리그 구조 확인.
- `art-rework`: 20개 드래곤의 정적/애니메이션 모델 경계 오차 최대 6.49e-8. 모바일 390×844, 펫 3종 동시 표시에서 3/4/19단계 draw calls 66/74/77, 최대 69,478 triangles. 브라우저 오류 없음.
- `regions`: 20개 실제 플레이 화면 및 반복 이동 검증 통과. 최대 33 draw calls, 55,258 triangles. 반복 이동 전후 geometry 317 / texture 3 유지.
- 빌드 성공. 전체 JS gzip 306,892 bytes = 299.70 KiB. 불필요한 기존 에셋 선로딩 제거. 기존 ID와 파일은 보존.
- 변경 TS/JS lint 통과. 전체 lint는 수정 범위 밖 QA 파일의 기존 오류 12개 때문에 실패. 테스트 삭제나 기준 완화 없음.

## 남은 제한

- 개발 서버 초기 전송량은 5,683,708 bytes로 4 MiB 목표를 초과했다. 프로덕션 검사는 로그인 선택 화면에서 대기하여 전체 로딩 측정을 완료하지 못했다. 341,546 bytes는 로그인 화면까지의 부분 측정이며 목표 통과로 해석할 수 없다.
- 물리적 모바일 기기 FPS, 토스 인증·안전영역은 확인하지 않았다. 모바일 화면 검수는 데스크톱 Edge의 390px viewport다.
- 기존 체형 일부는 재사용한다. 모든 개체를 완전히 다른 원형으로 새 제작한 것은 아니다. 일부 육중한 몸통과 전경 수호자의 가림은 추가 미술 조정 여지가 있다.
- VOX는 원형 복셀 데이터다. 최종 회전 자세는 JSON 리그가 제공하므로 외부 VOX 뷰어에서 같은 자세가 자동 재현되지는 않는다.
